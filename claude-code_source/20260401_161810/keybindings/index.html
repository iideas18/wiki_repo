💡 Think of it like a telephone switchboard

Imagine an old telephone switchboard where an operator routes calls based on the number dialed and the caller's location. The keybinding system works the same way: a keystroke comes in (the "call"), the parser decodes it into a normalized key string, the resolver checks what context you're in (Chat? Autocomplete? File picker?) and consults the binding table — first user overrides, then defaults. If the key is the first half of a chord (like Ctrl+K followed by Ctrl+C), the system waits for the second key before connecting you to the right action. Reserved shortcuts (terminal control keys) are never intercepted, just like emergency numbers that always go straight through.

Deep-Dive Topics

🔑 Key Resolution

The resolver walks the context stack from most-specific to least-specific. A binding in the Autocomplete context beats the same key in Global. User overrides always take priority over defaults at the same context level. The chord state machine has three states: Idle, Pending (first key of chord received), and Complete (full chord matched). A configurable timeout (default 1500ms) auto-resets from Pending to Idle if the second key never arrives.

🎹 Chord Matching

Chords are multi-key sequences like Ctrl+K Ctrl+C. When the resolver enters Pending state, a visual indicator appears in the status bar showing the partial chord. The matcher supports arbitrary-length chords but recommends a maximum of two keys. Chord definitions in the binding table use space-separated key strings: "ctrl+k ctrl+c".

export interface KeyBinding {
  key: string;          // e.g. "ctrl+shift+p" or "ctrl+k ctrl+c"
  command: string;      // action identifier
  when?: string;        // context expression
  args?: unknown;       // optional arguments to pass to the action
  priority?: number;    // override default priority (higher wins)
}

Platform Detection

// Platform-specific key formatting
export function formatShortcut(key: string): string {
  const isMac = process.platform === 'darwin';
  return key
    .replace(/ctrl/gi,  isMac ? '⌃' : 'Ctrl')
    .replace(/alt/gi,   isMac ? '⌥' : 'Alt')
    .replace(/shift/gi, isMac ? '⇧' : 'Shift')
    .replace(/meta/gi,  isMac ? '⌘' : 'Win')
    .replace(/\+/g,     isMac ? '' : '+');
}
