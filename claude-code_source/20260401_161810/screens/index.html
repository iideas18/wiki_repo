💡 Think of it like TV channels on a television

A television has multiple channels, but only one is displayed at a time on the full screen. You switch between news, sports, and movies — each channel fills the entire display with its own layout, content, and controls. The screens module works identically: the REPL screen is the "main channel" where you interact with Claude, the Doctor screen is the "diagnostics channel" that checks system health, and ResumeConversation is the "previously on…" channel that lets you pick up where you left off. Only one screen occupies the terminal at a time.

Configuration

Each screen receives shared configuration through React context. The screen router manages transitions and passes the appropriate props. Key configuration patterns include:

// Screen component interface
export interface ScreenProps {
  config: AppConfig;
  theme: ThemeConfig;
  onNavigate: (screen: ScreenName) => void;
  onExit: () => void;
}

export type ScreenName = 'repl' | 'doctor' | 'resume';

// REPL-specific props
export interface ReplScreenProps extends ScreenProps {
  resumeSessionId?: string;
  initialPrompt?: string;
  model: ModelIdentifier;
  tools: ToolRegistry;
  onQueryComplete: (result: QueryResult) => void;
}

// Doctor check definitions
export interface DiagnosticCheck {
  name: string;
  category: 'keybinding' | 'mcp' | 'settings' | 'network' | 'permissions';
  run: () => Promise<DiagnosticResult>;
  severity: 'error' | 'warning' | 'info';
}

export interface DiagnosticResult {
  passed: boolean;
  message: string;
  details?: string;
  duration: number;
  fix?: string;
}

// Resume session entry
export interface SavedSession {
  id: string;
  title: string;
  model: string;
  lastMessage: string;
  messageCount: number;
  tokenCount: number;
  createdAt: string;
  updatedAt: string;
}

The Doctor screen runs all diagnostics in parallel and presents results grouped by category. Each check includes an optional fix field with a suggested remediation command. The REPL screen supports both fresh and resumed sessions through the resumeSessionId prop.
