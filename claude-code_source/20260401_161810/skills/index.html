Skill Discovery & Execution

20 files implementing the skill system that allows Claude to discover, load, and execute specialized capabilities. Skills are modular extensions that provide domain-specific knowledge and workflows, loaded from project or user directories.

💡 Think of it like a Toolkit Bag with Labeled Compartments

Imagine a professional's toolkit bag where each compartment holds a specialized tool — a voltmeter for electricians, a stethoscope for doctors, a set of lockpicks for locksmiths. The Skills module is Claude's toolkit bag. Each "skill" is a self-contained compartment with its own instructions, tools, and domain knowledge. When a user asks Claude to do something specialized (like "optimize my resume" or "analyze this stock"), the skill discovery system searches the toolkit bag, finds the right compartment, validates it hasn't been tampered with, and hands Claude the specialized tools inside. Skills can come pre-installed (built-in), from the project directory, or from the user's personal collection.

Code Examples

Discovering and Loading Skills

import { SkillRegistry } from './skill_registry';
import { discoverSkills } from './skill_discovery';
import { SkillLoader } from './skill_loader';

// Initialize the skill system
const registry = new SkillRegistry();
const loader = new SkillLoader();

// Discover skills from all sources
const discovered = await discoverSkills({
  projectDir: '/workspace/my-project/.claude/skills',
  userDir: '~/.claude/skills',
  includeBuiltIn: true,
});

console.log(`Discovered ${discovered.length} skills`);

// Register all discovered skills
for (const manifest of discovered) {
  const loaded = await loader.loadSkill(manifest);
  registry.registerSkill(loaded);
  console.log(`Registered: ${loaded.name} (${loaded.scope})`);
}

// List available skills
const available = registry.listSkills();
available.forEach(s => {
  console.log(`  ${s.name}: ${s.description} [${s.scope}]`);
});

Executing a Skill

import { SkillMatcher } from './skill_matcher';
import { SkillExecutor } from './skill_executor';
import type { SkillContext } from './types';

const matcher = new SkillMatcher(registry);
const executor = new SkillExecutor();

// Match user intent to a skill
const userMessage = 'optimize my resume for this job posting';
const match = matcher.findBestMatch(userMessage);

if (match) {
  console.log(`Matched skill: ${match.skill.name} (confidence: ${match.confidence})`);

  // Build execution context
  const context: SkillContext = {
    userMessage,
    workingDir: process.cwd(),
    sessionId: 'sess-abc-123',
    availableTools: ['bash', 'view', 'edit', 'create'],
  };

  // Execute the skill
  const result = await executor.executeSkill(match.skill, context);
  console.log(`Skill completed: ${result.status}`);
  console.log(`Output: ${result.output}`);
} else {
  console.log('No matching skill found');
}
