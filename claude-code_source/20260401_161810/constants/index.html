💡 Think of it like a building's blueprints and regulations handbook

Every building project has a thick handbook of codes and regulations — maximum occupancy, fire exit widths, electrical load limits, approved materials. Nobody rewrites these rules per project; they're referenced from a single authoritative source. The constants/ module is that handbook for Claude Code. It's the single source of truth for every magic number, API endpoint, token limit, and error ID used across the entire application. Change the image upload limit here and every tool that checks file size picks it up automatically.

Deep-Dive Topics

📡 API Configuration

API limits define hard boundaries enforced before requests reach the network layer. The image upload limit of 5MB is checked by the file-reading tools; PDFs are rejected above 100 pages by the PDF tool. Token budgets are split between system prompt, conversation history, and model response. These values are compile-time constants — changing them requires a rebuild, not a config file edit.

📝 System Prompts

The system prompt is assembled from named sections defined in systemPromptSections.ts. Each section (identity, capabilities, safety, tools, memory) can be independently versioned. The cyberRiskInstruction.ts section is always injected and cannot be disabled. Turn completion verbs add natural variation to how the model signals it's finished with a turn.
