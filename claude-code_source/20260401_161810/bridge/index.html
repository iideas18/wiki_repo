💡 Think of it like a Diplomatic Embassy

The Bridge module acts like an embassy between two sovereign systems — the Claude Code CLI and IDE extensions. Just as an embassy translates diplomatic messages between countries with different languages and protocols, the Bridge translates commands, selections, edits, and diagnostics between Claude's internal representation and the IDE's native APIs. WebSocket connections serve as the secure communication channels, while typed message handlers act as specialized attachés handling specific diplomatic portfolios: text selections, file changes, terminal commands, and diagnostic reports.

Code Examples

Initializing the Bridge

import { BridgeManager } from './bridge_manager';
import { MessageRouter } from './message_router';
import { SelectionTracker } from './selection_tracker';
import { DiagnosticsRelay } from './diagnostics_relay';

// Create and configure the bridge
const router = new MessageRouter();
const bridge = new BridgeManager({
  port: 0,               // auto-select port
  host: '127.0.0.1',
  heartbeatInterval: 15000,
  maxConnections: 4,
});

// Register handlers
router.registerHandler('selection.changed', SelectionTracker.handleSelectionChange);
router.registerHandler('diagnostics.updated', DiagnosticsRelay.handleDiagnosticsUpdate);

// Start the bridge server
await bridge.start(router);
console.log(`Bridge listening on port ${bridge.port}`);

Sending an Edit to the IDE

import { BridgeMessage, MessageType } from './protocol';
import type { EditPayload } from './protocol';

// Construct a typed edit message
const editMessage: BridgeMessage<EditPayload> = {
  type: MessageType.EditApply,
  id: crypto.randomUUID(),
  payload: {
    file: '/workspace/src/index.ts',
    patches: [
      {
        range: { startLine: 10, startCol: 0, endLine: 10, endCol: 25 },
        newText: 'const result = await compute();',
      },
    ],
  },
};

// Send through the bridge and await acknowledgment
const response = await bridge.send(editMessage);
if (response.payload.success) {
  console.log('Edit applied successfully in IDE');
}
