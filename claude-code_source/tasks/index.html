Background Task Management

12 files across 5 sub-directories implementing background task execution. Supports local shell tasks, local agent tasks, remote agent tasks, dream tasks, and workflow tasks. Each task type has its own execution strategy with progress tracking and lifecycle management.

💡 Think of it like a Restaurant Kitchen with Multiple Stations

A busy restaurant kitchen has specialized stations — the grill station, the sauté station, the pastry station — each with its own chef, tools, and techniques. The Tasks module works the same way. The "kitchen" is the task registry that tracks all active orders. Each "station" is a task type: LocalShellTask is the grill (runs shell commands), LocalAgentTask is the sauté station (runs local AI agents), RemoteAgentTask is the catering partner (delegates to remote agents), and DreamTask is the experimental tasting kitchen (runs speculative tasks). Every order has a ticket (progress tracking) and follows the same lifecycle: received → in progress → quality check → served (or sent back).

Code Examples

Creating and Running a Shell Task

import { TaskRegistry } from './tasks';
import type { TaskConfig, TaskResult } from './types';

const registry = new TaskRegistry();

// Create a shell task
const task = await registry.createTask('local-shell', {
  command: 'npm run build',
  workingDir: '/workspace/my-project',
  timeout: 120_000,      // 2 minute timeout
  captureOutput: true,
});

// Listen for progress
task.on('progress', (update) => {
  console.log(`[${update.percent}%] ${update.message}`);
});

// Start execution
const result: TaskResult = await task.start();

if (result.status === 'completed') {
  console.log(`Build succeeded in ${result.duration}ms`);
  console.log(`Output: ${result.output}`);
} else if (result.status === 'failed') {
  console.error(`Build failed: ${result.error}`);
  console.error(`Stderr: ${result.stderr}`);
}

Running a Local Agent Task

import { TaskRegistry } from './tasks';

const registry = new TaskRegistry();

// Create a local agent task for code exploration
const agentTask = await registry.createTask('local-agent', {
  prompt: 'Find all TypeScript files that import from the auth module and summarize their purpose',
  model: 'claude-haiku',
  tools: ['grep', 'glob', 'view'],
  workingDir: '/workspace/my-project',
  timeout: 60_000,
});

// Track progress
agentTask.on('progress', (update) => {
  console.log(`Agent: ${update.message}`);
});

// Run and get result
const result = await agentTask.start();
console.log(`Agent result: ${result.output}`);

// List all active tasks
const activeTasks = registry.listTasks({ status: 'running' });
console.log(`Active tasks: ${activeTasks.length}`);

// Cancel a task if needed
await registry.cancelTask(agentTask.id);

// Clean up completed tasks
registry.pruneCompleted({ olderThan: 3600_000 });

Task Concurrency with Queue

import { TaskQueue } from './task_queue';
import { TaskRegistry } from './tasks';

const registry = new TaskRegistry();
const queue = new TaskQueue({ maxConcurrent: 3 });

// Enqueue multiple tasks — only 3 run at a time
const tasks = [
  { type: 'local-shell', config: { command: 'npm test -- --shard=1/4' } },
  { type: 'local-shell', config: { command: 'npm test -- --shard=2/4' } },
  { type: 'local-shell', config: { command: 'npm test -- --shard=3/4' } },
  { type: 'local-shell', config: { command: 'npm test -- --shard=4/4' } },
];

const results = await queue.runAll(
  tasks.map(t => () => registry.createTask(t.type, t.config).then(task => task.start()))
);

const passed = results.filter(r => r.status === 'completed').length;
console.log(`${passed}/${results.length} test shards passed`);
