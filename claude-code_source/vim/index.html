💡 Think of it like a musical instrument with modes

A keyboard synthesizer has different modes — one where pressing keys plays notes, another where they control parameters like volume or pitch bend. Vim works the same way: in NORMAL mode, keys are commands (motions, operators); press i and you switch to INSERT mode where keys type text. This module recreates that dual-personality behavior inside Claude Code's input field, so Vim veterans can navigate and edit with muscle memory intact.

Configuration

Vim mode is toggled via the user's settings. When enabled, the input field intercepts all keypresses and routes them through the Vim state machine. Configuration options include:

// Vim configuration from settings
export interface VimConfig {
  enabled: boolean;
  startInInsertMode: boolean;
  showModeIndicator: boolean;
  clipboard: 'unnamed' | 'unnamedplus' | 'internal';
  customMappings: Record<string, string>;
}

// Default Vim settings
export const defaultVimConfig: VimConfig = {
  enabled: false,
  startInInsertMode: false,
  showModeIndicator: true,
  clipboard: 'internal',
  customMappings: {
    'jk': '<Escape>',  // common insert-mode escape mapping
  },
};

// Motion registry pattern
const motionMap: Record<string, MotionFn> = {
  'h': moveLeft,
  'l': moveRight,
  'j': moveDown,
  'k': moveUp,
  'w': wordForward,
  'b': wordBackward,
  'e': wordEnd,
  '0': lineStart,
  '$': lineEnd,
  'gg': fileStart,
  'G': fileEnd,
};

The customMappings field allows users to define key sequence remappings. The mode indicator (when enabled) displays the current mode in the input field's status bar.
