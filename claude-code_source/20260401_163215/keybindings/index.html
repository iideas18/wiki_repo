💡 What is this?

The keybindings module provides the complete keyboard shortcut infrastructure for Claude Code's terminal UI. It supports Vim and Emacs presets out of the box, lets users override any binding, and exposes a React hook so components can respond to key events.

🧩 Analogy: Think of it like VS Code's keybinding system

Just as VS Code has a keybindings.json where users override defaults, and a resolver that maps key chords to commands, this module provides the same layered approach: default presets (Vim/Emacs), user overrides (config file), a parser that normalizes key events, and a resolver that produces the final command to execute.

🚶 Step-by-Step Narrated Walkthrough

Follow a single Ctrl+K keypress through the keybinding pipeline:

  1. Key Event — Browser/terminal emits a keydown event with ctrlKey: true, key: "k".
  2. React Capture — The KeybindingProvider context wrapper captures the raw key event.
  3. Normalization — parse.ts normalizes the event into a canonical string: "ctrl+k".
  4. Mode Selection — The resolver checks the active mode (Vim, Emacs, or Custom).
  5. User Override Check — User config is checked first; if "ctrl+k" has a custom binding, it wins.
  6. Default Lookup — If no user override, the default preset for the active mode is consulted.
  7. Command Resolution — The matched binding returns a command name, e.g., "clearScreen".
  8. Hook Notification — useKeybinding("clearScreen") fires its callback in the subscribed component.
  9. Action Execution — The component handler clears the screen and re-renders the REPL.

Code Example

import { useKeybinding } from "./keybindings/hook";
import { KeybindingProvider } from "./keybindings/KeybindingProviderSetup";

// Wrap app with provider
function App() {
  return (
    <KeybindingProvider mode="vim">
      <ReplView />
    </KeybindingProvider>
  );
}

// In a component, subscribe to a command
function ReplView() {
  useKeybinding("clearScreen", () => {
    clearTerminal();
  });

  useKeybinding("submitInput", () => {
    handleSubmit(currentInput);
  });

  return <div>{/* REPL UI */}</div>;
}
