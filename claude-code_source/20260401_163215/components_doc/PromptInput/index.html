📚 What is this & why does it exist?

PromptInput is the text field at the bottom of the Claude Code terminal UI where you type every message. It handles multi-line editing, remembers your previous prompts, shows slash-command suggestions as you type, and wires up keyboard shortcuts (Ctrl+C to cancel, Escape to clear, Up/Down to navigate history). Without it, there would be no way to communicate with the AI assistant.

💡 Real-world analogy

Think of PromptInput like the concierge desk at a hotel. You walk up and state your request (typing a prompt). The concierge remembers your previous requests (history navigation), suggests services as you start to speak (slash-command autocomplete), handles special instructions ("cancel that", "switch to plan mode"), and routes your request to the right department (mode switching). The desk itself adapts—expanding for longer requests, shrinking back for quick questions.

Performance Notes

Input Debouncing

Autocomplete filtering is debounced at 50 ms to prevent excessive re-renders during fast typing. The completion list is pre-filtered on the main thread since the command registry is small (typically <30 commands), making web worker offloading unnecessary.

History Memory

The input history is capped at 100 entries and persisted to AppState.inputHistory. Entries are deduplicated—submitting the same prompt twice moves it to the top instead of creating a duplicate. The history array is stored as a simple JSON-serializable list with no circular references.

Paste Detection

Multi-line pastes are detected by checking if the input length increases by more than one character in a single event cycle. Pastes exceeding 20 lines trigger a confirmation dialog to prevent accidental submission of large clipboard contents. The paste handler also normalizes line endings (CRLF → LF) and strips trailing whitespace from each line.

Code Examples

Example: Handling Submit with History Push

// Inside PromptInput — simplified submit handler
const handleSubmit = useCallback((text: string) => {
  if (!text.trim() || isLoading) return;

  // Push to history before dispatching
  inputHistory.push({ text, timestamp: Date.now() });

  // Check for slash command prefix
  if (text.startsWith('/')) {
    const cmd = commands.find(c => text.startsWith('/' + c.name));
    if (cmd) {
      cmd.run(text.slice(cmd.name.length + 2).trim());
      return;
    }
  }

  onSubmit(text);
}, [isLoading, commands, onSubmit, inputHistory]);

Example: Autocomplete Filtering

// Slash command autocomplete with fuzzy prefix matching
function getCompletions(input: string, commands: Command[]): AutocompleteItem[] {
  if (!input.startsWith('/')) return [];
  const query = input.slice(1).toLowerCase();

  return commands
    .filter(cmd => cmd.name.toLowerCase().startsWith(query))
    .slice(0, 8)
    .map(cmd => ({
      name: cmd.name,
      description: cmd.description,
      argHint: cmd.argHint ?? '',
    }));
}

Example: History Navigation Hook

// useInputHistory hook — manages Up/Down arrow history navigation
function useInputHistory(history: InputHistoryEntry[]) {
  const [historyIndex, setHistoryIndex] = useState(-1);
  const [draft, setDraft] = useState('');

  const navigateUp = useCallback(() => {
    if (historyIndex < history.length - 1) {
      if (historyIndex === -1) setDraft(currentInput);
      setHistoryIndex(prev => prev + 1);
      return history[historyIndex + 1]?.text ?? '';
    }
    return null; // At oldest entry
  }, [historyIndex, history]);

  const navigateDown = useCallback(() => {
    if (historyIndex > 0) {
      setHistoryIndex(prev => prev - 1);
      return history[historyIndex - 1]?.text ?? '';
    }
    if (historyIndex === 0) {
      setHistoryIndex(-1);
      return draft; // Restore current draft
    }
    return null; // Not in history
  }, [historyIndex, draft, history]);

  return { navigateUp, navigateDown, resetHistory };
}
