💡 What is this?

The types module is the type foundation of Claude Code. It provides the shared TypeScript interfaces, union types, branded IDs, and type guards that ensure type safety across all modules. No runtime code lives here — only type definitions and type-level utilities.

🧩 Analogy: Think of it like a blueprint library

Just as an architect's blueprint library contains the standard drawings referenced by every building plan (door specs, window specs, structural beam sizes), the types module contains the standard type blueprints referenced by every module. Message is the blueprint for all conversation messages, SessionId is the standard for session identifiers, and PermissionRule is the standard for access control entries.

🚶 Step-by-Step Narrated Walkthrough

Follow how a Message type is used across the codebase:

  1. Definition — message.ts defines the Message discriminated union: UserMessage | AssistantMessage | SystemMessage | ToolResult.
  2. Import — The agent module imports Message from "../types" to type conversation arrays.
  3. Construction — When the user types input, a UserMessage is created with role: "user" and content: string.
  4. API Serialization — The API module uses the Message type to build the request body for the Anthropic API.
  5. Response Parsing — API responses are parsed into AssistantMessage objects with ContentBlock[] arrays.
  6. Tool Calls — If the assistant message contains tool calls, each is typed as ToolCall with a branded ToolCallId.
  7. Type Guards — Functions like isUserMessage(msg) narrow the union to the specific variant for safe property access.
  8. State Storage — The state module stores Message[] arrays keyed by branded SessionId values.

Code Example

import type {
  Message,
  UserMessage,
  AssistantMessage,
  SessionId,
  PermissionRule,
} from "../types";
import { createSessionId, isUserMessage } from "../types";

// Create a branded session ID (cannot accidentally use a raw string)
const sessionId: SessionId = createSessionId();

// Build a typed message array
const messages: Message[] = [
  { role: "user", content: "Hello", id: createMessageId() },
];

// Use type guards for safe narrowing
function getLastUserInput(msgs: Message[]): string | undefined {
  const last = msgs.findLast(isUserMessage);
  return last?.content; // TypeScript knows this is UserMessage
}

// Permission rules with full type safety
const rule: PermissionRule = {
  mode: "auto-allow",
  scope: "bash",
  pathPattern: "src/**",
};
