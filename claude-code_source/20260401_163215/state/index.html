💡 What is this?

The state module is the centralized state management layer for Claude Code's React-based terminal UI. It uses Zustand (a lightweight alternative to Redux) to create a single store that holds all application state, from conversation messages to the current permission prompt.

🧩 Analogy: Think of it like a flight control tower

Just as a flight control tower is the single source of truth for all aircraft positions, runway status, and weather conditions — and every controller queries the same shared state — the Zustand store is the single source of truth for all UI state. Components don't talk to each other directly; they read from and write to the store, and the store notifies them of changes.

🚶 Step-by-Step Narrated Walkthrough

Follow a user message submission through the state management pipeline:

  1. User Input — The user types a message and presses Enter in the REPL input component.
  2. Dispatch — The component calls store.getState().addMessage(userMessage) to add it to state.
  3. Immutable Update — Zustand produces a new state object with the message appended to messages[].
  4. Change Notification — onChangeAppState fires registered listeners with the old and new state.
  5. Selector Recompute — Selectors like selectLastMessage and selectIsWaiting recompute their derived values.
  6. React Re-render — Components subscribed via useAppState(selectMessages) re-render with the new message list.
  7. API Side Effect — A listener triggers the API call, sending the new message to the Anthropic API.
  8. Response Dispatch — When the API responds, the assistant message is dispatched back to the store.
  9. Cycle Repeats — The store updates again, selectors recompute, and the UI shows the assistant reply.

Code Example

import { AppStateProvider, useAppState } from "./state/AppState";
import { selectMessages, selectIsWaiting } from "./state/selectors";
import { onChangeAppState } from "./state/onChangeAppState";

// Wrap the app with the state provider
function App() {
  return (
    <AppStateProvider>
      <ReplView />
    </AppStateProvider>
  );
}

// Subscribe to state slices in a component
function ReplView() {
  const messages = useAppState(selectMessages);
  const isWaiting = useAppState(selectIsWaiting);

  return (
    <div>
      {messages.map((msg) => (
        <MessageBubble key={msg.id} message={msg} />
      ))}
      {isWaiting && <Spinner />}
    </div>
  );
}

// Listen for state changes outside React
onChangeAppState((prev, next) => {
  if (prev.messages.length !== next.messages.length) {
    persistConversation(next.messages);
  }
});
