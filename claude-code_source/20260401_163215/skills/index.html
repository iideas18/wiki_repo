💡 What is this?

The skills module is the extensibility backbone of Claude Code. It allows users and the system to register prompt-based commands that the AI model can discover and invoke at runtime, turning the CLI into a fully extensible platform.

🧩 Analogy: Think of it like browser extensions

Just as browser extensions add new capabilities to a browser without modifying its core, skills add new prompt-based commands to Claude Code. User skills are like personal extensions installed from local files, bundled skills are like pre-installed extensions that ship with the browser, and MCP skills are like extensions fetched from a remote marketplace.

🚶 Step-by-Step Narrated Walkthrough

Follow a single user skill invocation as it flows through the skills pipeline:

  1. Trigger — User types /my-skill in the REPL or the model decides to invoke a registered skill.
  2. Registry Lookup — SkillRegistry searches all three sources (user, bundled, MCP) for a matching skill name.
  3. Directory Scan — For user skills, loadSkillsDir.ts reads .claude/skills/ and parses the skill definition YAML/markdown.
  4. Validation — The skill schema is validated: required fields (name, prompt), optional fields (description, parameters).
  5. Template Parsing — The skill prompt template is loaded, with placeholder tokens identified for variable injection.
  6. Context Injection — Runtime context (current file, selection, project root) is injected into the prompt template.
  7. Prompt Assembly — The finalized skill prompt is appended to the conversation as a system-level message.
  8. Model Execution — The AI model receives the enriched prompt and executes the skill instructions.
  9. Result Capture — Output from the skill execution is captured and displayed to the user in the REPL.

Code Example

import { SkillRegistry } from "./registry";
import { loadSkillsDir } from "./loadSkillsDir";
import { bundledSkills } from "./bundledSkills";
import { mcpSkillBuilders } from "./mcpSkillBuilders";

// Initialize registry with all skill sources
const registry = new SkillRegistry();
registry.registerAll(bundledSkills);
registry.registerAll(await loadSkillsDir(".claude/skills/"));
registry.registerAll(await mcpSkillBuilders.build(mcpServers));

// Resolve and execute a skill
const skill = registry.lookup("quick-diff");
if (skill) {
  const prompt = skill.resolve({ filePath: "src/index.ts" });
  await executor.run(prompt, conversationContext);
}
