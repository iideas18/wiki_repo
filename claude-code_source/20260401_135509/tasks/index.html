Tasks — Multi-Task Execution Engine

Multi-Task Execution Engine

The Tasks module manages the lifecycle of background and foreground work items in Claude Code. It orchestrates shell commands, local agents, remote cloud sessions, in-process teammates, and autonomous dream (memory consolidation) tasks — all with progress tracking, abort control, and UI notification.

💡 Think of it like…

An operating system process scheduler. Just as an OS kernel manages processes with different priorities, states (running, sleeping, zombie), and execution contexts (user-space, kernel threads, remote RPC), the Tasks module manages shell processes, local AI agents, remote cloud sessions, and teammate workers — each with their own state machine, abort signal, and progress reporting pipeline.

🚶 Step-by-Step Narrated Walkthrough

Follow a background shell command from spawn to completion notification:

  1. Spawn Request — The AI invokes Bash tool; spawnShellTask() is called with the command string and execution context.
  2. Registration — registerForeground() creates a LocalShellTaskState with a unique nanoid, sets isBackgrounded: false, and inserts it into AppState.
  3. Process Spawn — The shell command is executed in a child process with pty allocation and output streaming.
  4. Stall Watchdog — startStallWatchdog() begins polling every 5 seconds; if no output for 45s, it checks the last 1024 bytes for interactive prompt patterns.
  5. Background Transition — User presses the background key; backgroundTask() flips isBackgrounded: true and the task moves to the footer pill.
  6. Pill Label — getPillLabel() aggregates all background tasks into a compact footer string with diamond indicators for ultraplan states.
  7. Completion — The process exits; enqueueShellNotification() creates a notification with exit code and task summary.
  8. Cleanup — flushAndCleanup() flushes remaining output and runs the registered cleanup callback via unregisterCleanup().
  9. State Removal — unregisterForeground() removes the task from AppState, completing its lifecycle.

Code Examples

Spawning a Background Shell Task

import { spawnShellTask, backgroundTask } from "./LocalShellTask/LocalShellTask";

// Spawn a shell command as a managed task
const handle = await spawnShellTask(
  { command: "npm run build", timeout: 60_000 },
  { getAppState, setAppState, agentId, toolUseId }
);

// Move task to background so the user can continue chatting
backgroundTask(handle.taskId, getAppState, setAppState);

Registering an Async Agent Task

import {
  registerAsyncAgent,
  completeAgentTask,
  updateAgentProgress,
} from "./LocalAgentTask/LocalAgentTask";

const task = registerAsyncAgent({
  agentId: "a-review-abc123def456",
  description: "Reviewing PR #42",
  prompt: "Review the changes in this pull request",
  selectedAgent: { name: "code-reviewer", type: "custom" },
  setAppState,
});

// Update progress as the agent works
updateAgentProgress(task.id, { toolUseCount: 5, tokenCount: 12000 }, setAppState);

// Mark as complete when done
completeAgentTask({ taskId: task.id, result: "LGTM" }, setAppState);
