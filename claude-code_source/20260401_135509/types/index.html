Types — Central Type Definitions

Central Type Definitions

The Types module is the shared type foundation for Claude Code. It defines the canonical shapes for commands, hooks, permissions, plugins, session logging, text input, and branded identifiers — consumed by virtually every other module in the codebase.

💡 Think of it like…

A data dictionary for a relational database. Just as a database schema defines every table, column, constraint, and relationship before any query runs, the Types module defines every message shape, permission rule, hook event, and branded ID before any runtime code executes. Every module imports from here; none defines its own core shapes independently.

🚶 Step-by-Step Narrated Walkthrough

Follow a permission check for a tool invocation through the type system:

  1. Tool Call Arrives — A Command (from command.ts) is matched; its CommandAvailability is checked against auth state.
  2. Agent ID Validation — The caller’s AgentId (from ids.ts) is validated against the AGENT_ID_PATTERN regex.
  3. Permission Rules Lookup — PermissionRule[] from multiple sources (PermissionRuleSource) are collected and checked in priority order.
  4. Classifier Evaluation — If no rule matches, the ClassifierResult determines confidence and whether to block.
  5. Decision Returned — A PermissionDecision (Allow | Ask | Deny) is produced with a PermissionDecisionReason tree.
  6. Hook Notification — The decision triggers a HookEvent (from hooks.ts); matching HookCallback handlers fire.
  7. Result Aggregation — Multiple hook results are merged into an AggregatedHookResult with blocking error tracking.
  8. Session Logging — The tool use is serialized as a SerializedMessage (from logs.ts) with SessionId metadata.
  9. Transcript Entry — A TranscriptMessage is appended to the session’s Entry union log for persistence.

Code Examples

Working with Branded IDs

import { asSessionId, asAgentId, toAgentId, AGENT_ID_PATTERN } from "./ids";

// Create branded IDs from raw strings
const sessionId = asSessionId("sess_abc123");
const agentId = asAgentId("a-review-1234567890abcdef");

// Validate an agent ID (returns null if invalid)
const validated = toAgentId("a-1234567890abcdef"); // AgentId
const invalid = toAgentId("not-an-agent-id");       // null

// Pattern: /^a(?:.+-)?[0-9a-f]{16}$/
console.log(AGENT_ID_PATTERN.test("a-review-1234567890abcdef")); // true

Building Permission Decisions

import type {
  PermissionAllowDecision,
  PermissionDenyDecision,
  PermissionRule,
  PermissionDecisionReason,
} from "./permissions";

// A rule from user settings allowing bash
const rule: PermissionRule = {
  source: "userSettings",
  ruleBehavior: "allow",
  ruleValue: { toolName: "Bash", ruleContent: "npm run *" },
};

// An allow decision with reason tracking
const allow: PermissionAllowDecision = {
  behavior: "allow",
  decisionReason: { type: "rule", rule, source: "userSettings" },
};

// A deny decision from classifier
const deny: PermissionDenyDecision = {
  behavior: "deny",
  message: "Command may modify system files outside project",
  decisionReason: { type: "classifier", confidence: "high" },
};
