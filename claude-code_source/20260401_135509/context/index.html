Context — React Context Providers

React Context Providers

The Context module provides a composable set of React context providers that supply global capabilities to the Ink-based terminal UI. Each file follows a consistent Provider/Hook pattern — wrapping state, subscriptions, and utilities behind clean React hooks for notifications, overlays, voice input, metrics collection, and inter-component messaging.

💡 Think of it like… a Building’s Utility Systems

Each context provider is like an independent utility system in a building. MailboxProvider is the internal mail room — components drop off and pick up messages. NotificationProvider is the PA system with priority announcements. OverlayProvider is the security desk tracking which doors (modals) are open. VoiceProvider is the intercom with recording/processing states. StatsProvider is the building’s energy monitoring system with counters, gauges, and histograms. Every tenant (component) plugs into exactly the utilities they need via hooks.

Notification Queue System

flowchart TD
  Add["addNotification(notif)"] --> PCheck{"priority?"}
  PCheck -- immediate --> Show["Show instantly\nclear timeout"]
  PCheck -- high/medium/low --> FoldCheck{"fold key exists?"}
  FoldCheck -- Yes --> Merge["Merge via fold fn"]
  FoldCheck -- No --> Enqueue["Add to queue"]
  Merge --> Process["processQueue()"]
  Enqueue --> Process
  Process --> GetNext["getNext(queue)\npriority sort"]
  GetNext --> Display["Display current"]
  Display --> Timeout["setTimeout\nDEFAULT_TIMEOUT_MS = 8s"]
  Timeout --> Process

🚶 Step-by-Step Narrated Walkthrough

Follow a single notification lifecycle through the Context pipeline:

  1. Dispatch — A component calls addNotification({ key: "save", priority: "high", text: "File saved" }).
  2. Priority Check — If priority is immediate, it bypasses the queue and displays instantly.
  3. Fold Check — If a notification with the same key exists and a fold function is provided, the notifications merge.
  4. Enqueue — The notification enters the priority queue (immediate=0, high=1, medium=2, low=3).
  5. Process Queue — getNext() selects the highest-priority notification from the queue.
  6. Display — The notification renders as either text (with optional color) or JSX content.
  7. Timeout — After DEFAULT_TIMEOUT_MS (8 seconds) or custom timeoutMs, the notification auto-dismisses.
  8. Invalidation — If the notification has invalidates keys, those queued notifications are removed.
  9. Cleanup — removeNotification(key) clears any notification by key at any point.

Code Examples

Priority Notification with Folding

import { useNotifications } from "./context/notifications";

function BatchProgress() {
  const { addNotification, removeNotification } = useNotifications();

  // Notifications with same key are merged via fold function
  addNotification({
    key: "batch-progress",
    priority: "high",
    timeoutMs: 10_000,
    text: "Processing item 1 of 50",
    fold: (existing, incoming) => ({
      ...incoming,
      text: `Processing item ${parseInt(existing.text.match(/\d+/)?.[0] ?? "0") + 1} of 50`,
    }),
  });

  // Remove programmatically when done
  removeNotification("batch-progress");
}

Voice State with Selector Subscription

import { useVoiceState, useGetVoiceState } from "./context/voice";

function VoiceIndicator() {
  // Only re-renders when recording state changes
  const isRecording = useVoiceState((s) => s.voiceState === "recording");
  const audioLevels = useVoiceState((s) => s.voiceAudioLevels);

  // Synchronous reader for event handlers (no re-render)
  const getState = useGetVoiceState();
  const handleKeyDown = () => {
    if (getState().voiceState === "idle") {
      startRecording();
    }
  };

  return isRecording ? <AudioMeter levels={audioLevels} /> : null;
}

Metrics Collection with Histograms

import { useCounter, useTimer } from "./context/stats";

function ApiCallTracker() {
  const countApiCall = useCounter("api_calls");
  const trackLatency = useTimer("api_latency_ms");

  async function callApi() {
    const start = Date.now();
    countApiCall();        // increment by 1
    await fetch("/api/...");
    trackLatency(Date.now() - start);  // reservoir-sampled histogram
  }
  // On process exit, stats are persisted via saveCurrentProjectConfig
  // Output keys: api_latency_ms_count, _min, _max, _avg, _p50, _p95, _p99
}

Overlay Registration for Escape Coordination

import { useRegisterOverlay, useIsModalOverlayActive } from "./context/overlayContext";

function SelectDropdown({ isOpen, onCancel }) {
  // Auto-registers when isOpen becomes true; unregisters on close/unmount
  useRegisterOverlay("select-dropdown", isOpen);

  return isOpen ? <DropdownMenu onCancel={onCancel} /> : null;
}

function InputField() {
  // Block input when a modal overlay is consuming Escape
  const blocked = useIsModalOverlayActive();
  // autocomplete is in NON_MODAL_OVERLAYS — doesn't block
  return <TextInput disabled={blocked} />;
}

Inter-Component Messaging via Mailbox

import { useMailbox } from "./context/mailbox";

function ToolExecutor() {
  const mailbox = useMailbox(); // throws if outside MailboxProvider

  // Send a message to any listening component
  mailbox.send("tool-complete", { toolId: "bash_123", exitCode: 0 });

  // Listen for messages from other components
  mailbox.on("user-interrupt", () => {
    abortCurrentTool();
  });
}
