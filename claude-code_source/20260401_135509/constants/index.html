Constants — Centralized Configuration Hub

Centralized Configuration Hub

The Constants module is the dependency-leaf of the Claude Code DAG — a flat collection of 21 TypeScript files that define API limits, beta headers, system prompts, OAuth configuration, tool availability matrices, Unicode figures, and XML tag vocabularies. By design it imports nothing from the rest of the codebase, preventing circular dependencies.

💡 Think of it like… a City Zoning Code Book

Just as a city’s zoning code book sits in its own binder that every department references but never modifies, the Constants module is the single source of truth that every other Claude Code module imports from. apiLimits is the building height restrictions. betas is the list of experimental permits. prompts is the master plan that generates the system’s “constitution.” tools is the allowlist of which contractors (agents) can use which equipment. Nobody sends mail back to the code book — it’s read-only by design.

🚶 Step-by-Step Narrated Walkthrough

Follow a single system prompt generation request through the Constants pipeline:

  1. Entry — getSystemPrompt(tools, model) is called with enabled tools and the model ID.
  2. Date Resolution — getSessionStartDate() returns a memoized ISO date (checking CLAUDE_CODE_OVERRIDE_DATE env var).
  3. Output Style — getOutputStyleConfig() merges built-in styles with custom and plugin styles via getAllOutputStyles().
  4. Static Sections — Cacheable sections (intro, system, actions, tone) are assembled. These rarely change per session.
  5. Cache Boundary — SYSTEM_PROMPT_DYNAMIC_BOUNDARY marker is inserted to split cache scope.
  6. Environment Info — computeEnvInfo() gathers OS, shell, git status, and knowledge cutoff for the model.
  7. Tool Gating — getUsingYourToolsSection() documents available tools; tools.ts matrices filter per agent type.
  8. MCP Instructions — getMcpInstructionsSection() lists connected MCP servers and their capabilities.
  9. Assembly — All sections are concatenated into the prompt array sent to the API with global cache scope prefix.

Tool Availability Gating

import {
  ASYNC_AGENT_ALLOWED_TOOLS,
  ALL_AGENT_DISALLOWED_TOOLS,
  COORDINATOR_MODE_ALLOWED_TOOLS,
} from "./constants/tools";

function getToolsForAgent(agentType: string, allTools: string[]): string[] {
  if (agentType === "coordinator") {
    return allTools.filter((t) => COORDINATOR_MODE_ALLOWED_TOOLS.has(t));
  }
  if (agentType === "async") {
    return allTools.filter((t) => ASYNC_AGENT_ALLOWED_TOOLS.has(t));
  }
  // Default: remove disallowed tools
  return allTools.filter((t) => !ALL_AGENT_DISALLOWED_TOOLS.has(t));
}

Binary File Detection

import { hasBinaryExtension, isBinaryContent, BINARY_EXTENSIONS } from "./constants/files";

// Fast path: check extension
if (hasBinaryExtension("image.png")) {
  console.log("Binary file — skip text processing");
}

// Thorough check: scan first 8192 bytes for null bytes
const buffer = await fs.readFile("mystery-file");
if (isBinaryContent(buffer)) {
  console.log("Binary content detected");
}

// BINARY_EXTENSIONS includes: images, video, audio, archives,
// executables, documents, fonts, bytecode, databases, lock files
console.log(BINARY_EXTENSIONS.size); // 100+ extensions
