🚶 Step-by-Step Narrated Walkthrough

Follow a single user message as it flows through the entire Components pipeline:

  1. PromptInput Capture — The user types into PromptInput. The BaseTextInput captures keystrokes, applies Vim bindings if enabled, and runs usePromptInputPlaceholder for dynamic hints.
  2. Autocomplete & Suggestions — ShimmeredInput overlays ghost-text suggestions from useTypeahead. The PromptInputFooter shows context-aware shortcuts and mode indicators.
  3. Submission — On Enter, the input text is dispatched to the command parser. PromptInputQueuedCommands handles queued multi-commands if present.
  4. Message Creation — The submitted text becomes a UserTextMessage rendered inside the Messages list via VirtualMessageList for efficient scrolling.
  5. Assistant Response Streaming — As the model responds, AssistantTextMessage renders streaming Markdown. SpinnerGlyph and GlimmerMessage provide visual feedback during generation.
  6. Tool Call Display — When the model invokes a tool, AssistantToolUseMessage displays the tool name and parameters. ToolUseLoader shows execution progress.
  7. Permission Gate — If the tool requires approval, PermissionRequest dispatches to the correct dialog: BashPermissionRequest for shell commands, FilePermissionDialog for file ops, WebFetchPermissionRequest for HTTP calls.
  8. User Decision — PermissionPrompt presents approve/deny/always-allow options. The user's choice is logged via usePermissionRequestLogging to analytics.
  9. Tool Result Rendering — After execution, UserToolResultMessage displays results. File diffs use FileEditToolDiff with syntax-highlighted structured diffs via StructuredDiff.
  10. Error Handling — If the API returns an error, SystemAPIErrorMessage renders troubleshooting guidance. RateLimitMessage handles rate-limit scenarios with upsell prompts.
  11. Task Background — Long-running operations appear in BackgroundTask cards. BackgroundTasksDialog provides a modal overview of all active tasks with progress via ShellProgress.
  12. Cycle Complete — The conversation scrolls to the latest message. The PromptInput re-focuses, ready for the next user query. StatusLine updates token usage and model info.

Sub-Modules

permissions/

51 files — Comprehensive permission system for tool access authorization with interactive dialogs and rule-based policies.

  • Bash, file, web fetch, sandbox permission dialogs
  • Rule editor with per-tool allow/deny/ask configuration
  • Analytics logging for permission decisions

messages/

41 files — Message rendering pipeline for all conversation types including assistant, user, system, and tool results.

  • Streaming Markdown rendering with syntax highlighting
  • Tool call visualization with parameter display
  • Error, rate-limit, and team collaboration messages

agents/

26 files — Agent creation and management UI with model selection, tool assignment, and color theming.

  • Agent editor with live validation
  • Model and tool multi-select pickers
  • Persist agent definitions to disk

PromptInput/

21 files — Main user input component with autocomplete, Vim bindings, voice mode, and paste handling.

  • Multiline text input with shimmer suggestions
  • History search and arrow-key navigation
  • Voice indicator and mode switching

design-system/

16 files — Reusable terminal UI primitive library providing consistent styling across the application.

  • Dialog, Pane, Tabs, FuzzyPicker primitives
  • Theme provider with color utilities
  • Keyboard shortcut hint components

mcp/

13 files — MCP server configuration UI for managing connections, browsing tools, and handling scoped configs.

  • Server list with project/local/user/enterprise scopes
  • Tool detail views with schema documentation
  • OAuth elicitation and reconnection dialogs

tasks/

12 files — Background task status visualization for shell, remote, agent, and dream operations.

  • Unified task card with type-based dispatch
  • Shell progress with elapsed time display
  • Detail dialogs for each task type

Spinner/

12 files — Loading spinner animations with shimmer effects, stall detection, and teammate tree views.

  • SpinnerGlyph with configurable animation modes
  • Shimmer and flash character effects
  • Teammate spinner tree for swarm mode

CustomSelect/

10 files — Reusable select and multi-select dropdowns with search, filtering, and keyboard navigation.

  • Single and multi-select variants
  • Arrow-key navigation with option grouping
  • Input field integration for search filtering

FeedbackSurvey/

9 files — Feedback collection system with survey UI, transcript sharing, and post-compaction surveys.

  • Debounced digit-input rating collection
  • Transcript share opt-in with API submission
  • Memory and post-compact survey hooks
