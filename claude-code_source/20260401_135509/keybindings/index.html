💡 What Is This Module?

Think of the keybindings module like a telephone switchboard operator. Every time you press a key, the “operator” (the parser) translates the raw electrical signal into a structured request, checks if a multi-part “chord” call is in progress, looks up the destination in a phonebook of bindings (defaults + user overrides), and finally patches the call through to the correct action handler. Reserved lines (like ctrl+c) are hardwired and can’t be rerouted, while the rest of the switchboard is fully reconfigurable via ~/.claude/keybindings.json.

🚶 Step-by-Step Narrated Walkthrough

Follow a single Ctrl+K keystroke as it flows through the entire Keybindings pipeline:

  1. Terminal receives keypress — The user presses Ctrl+K. The terminal emits a control sequence that Ink captures as input="k" with key.ctrl=true.
  2. useKeybinding fires — The useInput hook in useKeybinding.ts receives the raw input and delegates to the KeybindingContext.resolve() method.
  3. Context list assembled — Active contexts are collected (e.g., ["Chat", "Global"]) and deduplicated so more specific contexts take priority.
  4. Resolver invoked — resolveKeyWithChordState() in resolver.ts receives the input, key, contexts, all parsed bindings, and the current pending chord state (null initially).
  5. Keystroke built — The resolver calls getKeyName() from match.ts to normalize the key name to "k", then constructs a ParsedKeystroke with {key:"k", ctrl:true, ...}.
  6. Chord prefix check — The resolver discovers that ctrl+k is a prefix for multi-key chords like ctrl+k ctrl+s (chat:killAgents) and ctrl+k ctrl+e (chat:externalEditor). It returns {type:"chord_started", pending:[ctrl+k]}.
  7. Pending state updated — useKeybinding calls setPendingChord([ctrl+k]) and calls event.stopImmediatePropagation() so no other handler processes this keypress.
  8. Second key arrives — The user presses K again (completing ctrl+x ctrl+k for “kill agents”). The resolver builds testChord [ctrl+x, ctrl+k], finds an exact match, and returns {type:"match", action:"chat:killAgents"}.
  9. Handler dispatched — The useKeybinding hook sees the action matches its registered action, invokes the handler, clears the pending chord, and stops propagation.
  10. Escape cancels chords — If Escape had been pressed instead, the resolver would return chord_cancelled, clearing the pending state and letting normal input resume.

Defining a Keybinding Block

// Each block targets a UI context and maps keystroke strings to actions
export const DEFAULT_BINDINGS: KeybindingBlock[] = [
  {
    context: 'Global',
    bindings: {
      'ctrl+c': 'app:interrupt',
      'ctrl+d': 'app:exit',
      'ctrl+l': 'app:redraw',
      'ctrl+t': 'app:toggleTodos',
      'ctrl+o': 'app:toggleTranscript',

      'enter':               'chat:submit',
    },
  },
  // ... 16 more context blocks
];

Matching a Keystroke

The match.ts module compares Ink’s raw key events against parsed bindings:

// Normalize key name from Ink's boolean flags
export function getKeyName(input: string, key: Key): string | null {
  if (key.escape) return 'escape';
  if (key.return) return 'enter';
  if (key.tab)    return 'tab';
  if (key.upArrow) return 'up';
  // ... arrow keys, pageUp/Down, etc.
  if (input.length === 1) return input.toLowerCase();
  return null;
}

// Full match: key name + all modifier flags must agree
export function matchesKeystroke(
  input: string, key: Key, target: ParsedKeystroke
): boolean {
  const keyName = getKeyName(input, key);
  if (keyName !== target.key) return false;
  // Alt and Meta collapse in terminals — both map to key.meta
  return modifiersMatch(getInkModifiers(key), target);
}

Using the React Hook

Components register shortcut handlers with useKeybinding:

// Single action
useKeybinding('app:toggleTodos', () => {
  setShowTodos(prev => !prev);
}, { context: 'Global' });

// Multiple actions in one hook (reduces useInput calls)
useKeybindings({
  'chat:submit':  () => handleSubmit(),
  'chat:cancel':  () => handleCancel(),
  'chat:stash':   () => handleStash(),
}, { context: 'Chat' });
