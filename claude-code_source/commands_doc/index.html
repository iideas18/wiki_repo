Commands

Slash Command System

The commands module implements 101 slash commands that serve as high-level user workflows. Commands can be prompt-based (multi-turn AI interactions with constrained tools), local (synchronous execution), or local-jsx (interactive React UI). The module uses a memoized registry pattern with lazy loading, feature gates, and environment-based availability filtering.

💡 How to Think About It

Think of the commands module like a restaurant menu: each slash command is a named dish with its own recipe. The registry (commands.ts) is the menu itself—indexed and searchable. Some dishes are cooked live by the AI chef (prompt commands), some are pre-made and served instantly (local commands), and some come with an interactive presentation at the table (local-jsx commands). Feature gates are the seasonal availability flags, and lazy loading means the kitchen only preps a dish when someone actually orders it.

        Registry->>Prompt: getPromptForCommand()

🚶 Walkthrough: Trace /commit

1
User types /commit in the REPL input.
2
REPL detects the / slash prefix and extracts the command name "commit".
3
findCommand("commit") searches the memoized COMMANDS array in commands.ts.
4
Module is lazy-loaded via the load() function which performs a dynamic import().
5
Command type is "prompt", so getPromptForCommand() is called to prepare the AI interaction.
6
System fetches recent git log and staged diff as context for the model.
7
Allowed tools are constrained to git add, git status, and git commit only.
8
Model analyzes the diff and generates a well-structured commit message.
9
User reviews the generated message, edits if desired, and confirms.
10
git commit is executed via the constrained BashTool with the approved message.

📖 Glossary

Prompt Command
A command that initiates a multi-turn AI conversation with constrained tool access and a specialized system prompt.
Local Command
A synchronous command that runs entirely client-side, returning text output without invoking the AI model.
Local-JSX Command
A command that renders an interactive React (Ink) component in the terminal for rich UI interactions.
Memoized Registry
The COMMANDS array is computed once and cached — subsequent calls to getCommands() return the same reference.
Feature Gate
A boolean check (often server-driven) that determines whether a command is available in the current session.
Constrained Tools
The allowedTools pattern limits which tools (Bash, file read/write, etc.) a prompt command may use during its AI turn.
