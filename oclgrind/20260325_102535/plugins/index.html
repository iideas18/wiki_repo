plugins — Analysis & Debugging Plugins

12 files · ~5 600 lines of C++ · 6 plugins extending core::Plugin

💡 What is this?

Think of Oclgrind's core simulator as an airport control tower that monitors every aircraft movement. The plugins module is the set of specialist ground-crew teams plugged into the tower's radio feed — one team inspects cargo manifests (MemCheck), another watches for runway conflicts (RaceDetector), a third verifies that no empty containers are shipped (Uninitialized), a fourth logs flight statistics (InstructionCounter), a fifth lets you walk out onto the tarmac with binoculars (InteractiveDebugger), and a sixth writes everything to the logbook (Logger). Each team subscribes only to the radio channels it cares about; the tower broadcasts events and every registered team responds independently.

Architecture & Class Hierarchy

Every plugin inherits from Plugin (defined in core/Plugin.h) and selectively overrides virtual hook methods. The core runtime calls these hooks at well-defined points during simulation — memory accesses, kernel boundaries, work-group barriers, and log messages.

Plugin Hook Dispatch Flow

When the simulator executes an instruction or accesses memory, it iterates over registered plugins and invokes the matching virtual hook. The sequence below shows a simplified memory-store dispatch touching MemCheck, RaceDetector, and Uninitialized.

Plugin Base Class (core/Plugin.h)

class Plugin
{
public:
  Plugin(const Context* context);
  virtual ~Plugin();

  // Memory access hooks
  virtual void memoryLoad(const Memory* memory,
                          const WorkItem* workItem,
                          size_t address, size_t size) {}
  virtual void memoryStore(const Memory* memory,
                           const WorkItem* workItem,
                           size_t address, size_t size,
                           const uint8_t* storeData) {}

  // Lifecycle hooks
  virtual void kernelBegin(const KernelInvocation* ki) {}
  virtual void kernelEnd(const KernelInvocation* ki) {}
  virtual void workGroupBarrier(const WorkGroup* wg,
                                uint32_t flags) {}

  // Thread-safety — override to return false to
  // force single-threaded simulation
  virtual bool isThreadSafe() const;

protected:
  const Context* m_context;
};

MemCheck — Bounds Validation on Load

void MemCheck::checkLoad(const Memory* memory,
                         size_t address, size_t size) const
{
  if (!memory->isAddressValid(address, size))
  {
    logInvalidAccess(true, memory->getAddressSpace(),
                     address, size);
    return;
  }

  if (memory->getBuffer(address)->flags & CL_MEM_WRITE_ONLY)
  {
    m_context->logError("Invalid read from write-only buffer");
  }

  // Check if memory is currently mapped for writing
  for (auto& region : m_mapRegions)
  {
    if (region.type == MapRegion::WRITE &&
        address < region.address + region.size &&
        address + size >= region.address)
    {
      m_context->logError(
        "Invalid read from buffer mapped for writing");
    }
  }
}

RaceDetector — Barrier Synchronisation

void RaceDetector::workGroupBarrier(
    const WorkGroup* workGroup, uint32_t flags)
{
  if (flags & CLK_LOCAL_MEM_FENCE)
  {
    syncWorkItems(workGroup->getLocalMemory(),
                  STATE(workGroup),
                  STATE(workGroup).wiLocal);
  }
  if (flags & CLK_GLOBAL_MEM_FENCE)
  {
    syncWorkItems(m_context->getGlobalMemory(),
                  STATE(workGroup),
                  STATE(workGroup).wiGlobal);
  }
}
