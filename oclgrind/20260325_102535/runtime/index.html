Oclgrind runtime — OpenCL ICD Runtime

Full OpenCL 1.2 API Implementation & ICD Dispatch Layer

The runtime module is Oclgrind’s public face: it implements every cl* function from the OpenCL specification, wrapping them around the internal Core simulation engine. It also provides the ICD (Installable Client Driver) dispatch table that lets OpenCL loaders discover and route API calls to Oclgrind, plus the oclgrind launcher binary that uses LD_PRELOAD injection to transparently redirect any OpenCL application.

📚 What is this module?

Think of the runtime module as a hotel concierge desk. An OpenCL application walks up and makes requests — “create a context,” “allocate a buffer,” “run this kernel.” The concierge (runtime) doesn’t do the work itself; it creates a tracking ticket (wrapper struct), validates the request, and delegates the actual heavy lifting to the hotel staff (the core module). The ICD dispatch table is like the hotel’s phone directory — it maps every possible guest request to the right concierge handler. The async queue is the concierge’s task board: commands are pinned, dependencies tracked, and work is dispatched in order, with completion callbacks notifying guests when their request is done.

2 — Async Command Queue

The AsyncQueue subsystem handles all enqueue operations. When a clEnqueue* call is made, the runtime creates a core::Command object, retains any referenced cl_mem or cl_kernel objects, attaches the event wait list, and hands it off to core::Queue::enqueue(). On completion, asyncQueueRelease fires callbacks, releases retained objects, and cleans up event references. Four static maps track the lifecycle: memObjectMap, kernelMap, eventMap, and waitListMap.

7 — Code Examples

7.1 — Platform & Device Initialization (runtime.cpp)

The ICD entry point lazily creates the singleton platform and device, reading memory sizes from environment variables:

CL_API_ENTRY cl_int CL_API_CALL clIcdGetPlatformIDsKHR(
  cl_uint num_entries, cl_platform_id* platforms, cl_uint* num_platforms)
{
  REGISTER_API;
  if (platforms && num_entries < 1)
    ReturnError(NULL, CL_INVALID_VALUE);

  if (!m_platform) {
    m_platform = new _cl_platform_id;
    m_platform->dispatch = m_dispatchTable;

    m_device = new _cl_device_id;
    m_device->dispatch = m_dispatchTable;
    m_device->globalMemSize  = oclgrind::getEnvInt(
      "OCLGRIND_GLOBAL_MEM_SIZE", DEFAULT_GLOBAL_MEM_SIZE, false);
    m_device->localMemSize   = oclgrind::getEnvInt(
      "OCLGRIND_LOCAL_MEM_SIZE", DEFAULT_LOCAL_MEM_SIZE, false);
    m_device->maxWGSize      = oclgrind::getEnvInt(
      "OCLGRIND_MAX_WGSIZE", DEFAULT_MAX_WGSIZE, false);
  }
  if (platforms)     platforms[0] = m_platform;
  if (num_platforms) *num_platforms = 1;
  return CL_SUCCESS;
}

7.2 — Async Enqueue Lifecycle (async_queue.cpp)

When a command completes, asyncQueueRelease tears down retained references and fires user callbacks:

void asyncQueueRelease(Command* cmd)
{
  // Release retained memory objects
  if (memObjectMap.find(cmd) != memObjectMap.end()) {
    list<cl_mem> memObjects = memObjectMap[cmd];
    while (!memObjects.empty()) {
      clReleaseMemObject(memObjects.front());
      memObjects.pop_front();
    }
    memObjectMap.erase(cmd);
  }

  // Release kernel (if this was a kernel command)
  if (cmd->type == Command::KERNEL) {
    clReleaseKernel(kernelMap[cmd]);
    kernelMap.erase(cmd);
    delete ((KernelCommand*)cmd)->kernel;
  }

  // Fire user event callbacks
  cl_event event = eventMap[cmd];
  for (auto &cb : event->callbacks)
    cb.first(event, event->event->state, cb.second);

  // Release wait-list events
  for (auto &e : waitListMap[cmd])
    clReleaseEvent(e);
  waitListMap.erase(cmd);
  clReleaseEvent(event);
}

7.3 — Launcher LD_PRELOAD Injection (oclgrind.cpp)

The oclgrind binary constructs preload paths and uses execvp to replace itself with the target application:

// Construct LD_PRELOAD with the Oclgrind runtime library
string ldPreload = libdir + "/liboclgrind-rt." + LIB_EXTENSION;
const char* oldLdPreload = getenv(LD_PRELOAD_ENV);
if (oldLdPreload) {
  ldPreload += ":";
  ldPreload += oldLdPreload;
}

setEnvironment(LD_LIBRARY_PATH_ENV, ldLibraryPath.c_str());
setEnvironment(LD_PRELOAD_ENV, ldPreload.c_str());

// Replace process with target application
if (execvp(appArgs[0], appArgs) == -1) {
  cerr << "[Oclgrind] Failed to launch target application" << endl;
  exit(1);
}
