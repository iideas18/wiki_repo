Claude Opus 4.5 Migration — Automated Model Migration

Cross-Platform Model Migration

Migrates codebases from Claude 4.x to Opus 4.5 across four major platforms: Anthropic API, AWS Bedrock, Google Vertex AI, and Azure. Performs automated string replacement, header cleanup, prompt adjustment, and generates a comprehensive migration summary.

📚 What is this & why does it exist?

When Anthropic releases a new model version like Opus 4.5, every codebase using Claude needs to be updated — model identifiers change, API headers may need adjustment, and system prompts should be tuned for the new model's capabilities. This skill automates the entire process: it scans the codebase, detects which platform SDK is being used, performs all necessary string replacements, cleans up deprecated headers, adjusts prompts for Opus 4.5 improvements, and produces a summary of every change made. It's designed as a one-shot migration that handles everything in a single pass.

💡 Real-world analogy

Imagine upgrading the engine in a fleet of vehicles. Each vehicle might be a sedan (Anthropic API), a truck (AWS Bedrock), an SUV (Google Vertex), or a van (Azure). The new engine (Opus 4.5) fits all of them, but each vehicle type needs different mounting brackets, wiring harnesses, and calibration settings. This skill is the master mechanic who knows every vehicle type, does the swap, reconnects everything correctly, and hands you a detailed service report — all in one visit.

Platform Support

☁️ Anthropic API (Direct)

Direct API calls using the Anthropic SDK. Replaces model strings in anthropic.messages.create() calls and updates the anthropic-version header.

  • Old: claude-3-opus-20240229, claude-3-5-sonnet-20241022
  • New: claude-opus-4-5-20260301
  • Header: anthropic-version: 2026-03-01

⚡ AWS Bedrock

Bedrock model IDs use a different naming convention. Also updates IAM policy references and inference profile ARNs.

  • Old: anthropic.claude-3-opus-20240229-v1:0
  • New: anthropic.claude-opus-4-5-20260301-v1:0
  • Region: Cross-region inference support

📌 Google Vertex AI

Vertex uses versioned model paths with @ separators. Updates both the model identifier and the publisher path.

  • Old: claude-3-opus@20240229
  • New: claude-opus-4-5@20260301
  • Endpoint: publishers/anthropic/models/

🔵 Azure

Azure deployment names and model references. Updates the deployment configuration and API version string.

  • Old: claude-3-opus deployment
  • New: claude-opus-4-5 deployment
  • API: api-version=2026-03-01

Prompt Tuning

Opus 4.5 introduces improved capabilities that affect system prompt design:

📈 Extended Context

Opus 4.5 supports larger context windows. The skill updates max_tokens values and removes unnecessary context-saving workarounds from system prompts.

🧠 Enhanced Reasoning

Removes explicit chain-of-thought instructions that are now handled natively by the model. Simplifies verbose system prompts that over-specified reasoning steps.

🎨 Improved Formatting

Cleans up format-forcing instructions (e.g., "always respond in JSON") where Opus 4.5 handles structured output more reliably without them.
