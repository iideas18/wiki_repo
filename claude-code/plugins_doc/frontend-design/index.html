📚 What is this & why does it exist?

AI-generated frontends tend to converge on the same bland aesthetic — blue gradients, rounded cards, generic sans-serif typography. Frontend Design exists to break that pattern. It's auto-invoked for all frontend work and forces Claude to first commit to a specific aesthetic direction before writing any code. The two-phase approach (Design Thinking → Implementation) ensures that every UI decision is intentional: from the typeface weights to the animation easing curves to the whitespace rhythm.

💡 Real-world analogy

Without this skill, asking AI to build a frontend is like asking a session musician to "play something nice" — you'll get technically competent but forgettable background music. With this skill, it's like hiring a music director who first asks "What genre? What mood? Who's the audience?" then selects specific instruments, keys, and arrangements before a single note is played. The result is a composition with identity, not just competence.

Aesthetic Directions

⬛ Minimalism

Maximum whitespace, restrained color, single typeface family. Every element earns its place. Inspired by Dieter Rams and Japanese design principles.

  • Colors: Monochrome with one accent
  • Type: Light weights, generous tracking
  • Motion: Subtle fades, 200ms transitions

🌈 Maximalism

Bold color collisions, layered textures, mixed type families. Energetic and attention-grabbing. Inspired by Memphis Group and 90s rave culture.

  • Colors: 5+ colors, high saturation
  • Type: Display faces, extreme weight contrast
  • Motion: Bouncy, spring physics, parallax

📻 Retro

Period-specific aesthetics from the 1950s–1990s. CRT scan lines, VHS tracking, pixel fonts, or neon grids. Authenticity over novelty.

  • Colors: Period-accurate palettes
  • Type: Monospace, bitmap, or era-specific
  • Motion: Glitch, flicker, step animations

🌿 Organic

Flowing shapes, natural color palettes, hand-drawn elements. Inspired by nature, biology, and growth patterns.

  • Colors: Earth tones, botanical greens
  • Type: Humanist sans, gentle serifs
  • Motion: Ease-in-out, wave, grow effects

💎 Luxury

Rich materials, gold accents, refined spacing. Communicates premium quality and exclusivity. Inspired by haute couture and fine jewelry.

  • Colors: Black, gold, deep jewel tones
  • Type: Elegant serifs, wide letter-spacing
  • Motion: Smooth reveals, Ken Burns zoom

🎲 Playful

Rounded shapes, bright colors, micro-interactions. Delightful and approachable. Inspired by toy design and children's illustration.

  • Colors: Primary colors, pastels
  • Type: Rounded sans, variable weights
  • Motion: Bounce, wiggle, confetti

📰 Editorial

Magazine-inspired layouts with strong grid systems, pull quotes, and dramatic image cropping. Content-first design.

  • Colors: High contrast, limited palette
  • Type: Serif headlines, sans body text
  • Motion: Scroll-triggered reveals

🚧 Brutalist

Raw, unpolished, intentionally confrontational. Exposed structure, system fonts, visible borders. Anti-design as a statement.

  • Colors: Black & white, no gradients
  • Type: Times New Roman, Courier, system
  • Motion: None or jarring transitions

🏛️ Art Deco

Geometric patterns, symmetry, metallic accents. 1920s glamour meets modern technology. Gatsby-era opulence.

  • Colors: Gold, black, emerald, ivory
  • Type: Geometric display faces
  • Motion: Reveal along geometric paths

⚙️ Industrial

Exposed grid, monospace type, dark backgrounds, utility-first. Inspired by factories, dashboards, and terminal interfaces.

  • Colors: Dark grays, caution yellow, red
  • Type: Monospace, condensed sans
  • Motion: Mechanical, linear timing

Anti-Patterns Checklist

The skill actively prevents these common AI-generated frontend pitfalls:

🚫 Generic Blue Gradient

Default blue-to-purple gradient backgrounds that make every site look like a SaaS landing page from 2020.

🚫 Rounded Card Monotony

Uniform border-radius: 12px cards in a grid — the visual equivalent of elevator music.

🚫 One-Weight Typography

Using a single font at a single weight for everything. No hierarchy, no personality, no visual rhythm.

🚫 Padding Uniformity

Identical spacing everywhere. Good design uses varied whitespace to create visual tension and hierarchy.
