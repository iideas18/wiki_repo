📚 What is this & why does it exist?

Agent SDK Dev removes the boilerplate friction from starting new Claude Agent SDK projects. The /new-sdk-app command asks a series of guided questions (language, project name, features), then scaffolds a complete project with proper structure, dependencies, and configuration. After scaffolding, a language-specific verifier agent (Python or TypeScript) validates that the generated code compiles, imports resolve, and the basic agent loop works correctly.

💡 Real-world analogy

Think of a car dealership's “build your vehicle” configurator. You answer questions about engine type, color, and features. The system generates a complete vehicle specification, sends it to the factory floor (scaffolding), and then runs quality checks before delivery (verification). Agent SDK Dev is that configurator for AI agent projects — you pick your language, name your app, choose features, and get a verified, ready-to-run project.

Verification Checks

🐍 Python Verification Steps

  1. Verify pyproject.toml has valid TOML syntax
  2. Create virtual environment (python -m venv .venv)
  3. Install dependencies (pip install -e .)
  4. Check all imports resolve correctly
  5. Run mypy type checking (if installed)
  6. Execute agent loop dry run (no API calls)
  7. Verify test file imports and structure

📘 TypeScript Verification Steps

  1. Verify package.json has valid JSON
  2. Verify tsconfig.json configuration
  3. Install packages (npm install)
  4. Run TypeScript compiler (tsc --noEmit)
  5. Check all module imports resolve
  6. Verify exported types are correct
  7. Execute agent loop dry run (no API calls)

Error Handling

The scaffolding and verification pipeline handles errors at each stage:

StageErrorRecovery
ScaffoldingDirectory already existsPrompt user: overwrite, rename, or cancel
ScaffoldingInvalid project nameSuggest sanitized name, re-prompt
VerificationDependency install failsReport missing packages, suggest manual fixes
VerificationType check errorsList specific errors with file:line, suggest corrections
VerificationAgent loop failsReport error trace, check API key configuration
