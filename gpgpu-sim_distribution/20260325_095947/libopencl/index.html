libopencl — OpenCL Runtime API

OpenCL 1.x Runtime API Translation Layer

Implements libOpenCL.so as a drop-in replacement for the NVIDIA OpenCL driver. OpenCL calls are translated into the same GPGPU-Sim simulator infrastructure used by CUDA — OpenCL source is compiled to PTX via nvopencl_wrapper, then loaded into the simulator's PTX parser for cycle-accurate execution.

💡 What is libopencl?

Analogy: If libcuda is the "customs checkpoint" for CUDA traffic, libopencl is the translator booth next door — it accepts OpenCL-speaking applications, translates their requests into the same internal language (PTX + kernel_info_t), and sends them through the same simulation pipeline. The translation includes compiling OpenCL C source to PTX and mapping OpenCL's NDRange work dimensions to CUDA-style grid/block dimensions.

🚶 Step-by-Step Narrated Walkthrough

Follow a single clEnqueueNDRangeKernel() call through the libopencl pipeline:

  1. Platform Discovery — clGetPlatformIDs() returns the singleton g_gpgpu_sim_platform_id. The application sees one GPGPU-Sim platform.
  2. Device Selection — clGetDeviceIDs() returns a _cl_device_id wrapping the simulated gpgpu_sim instance.
  3. Context Creation — clCreateContext() creates a _cl_context binding the device, initialising the memory map m_hostptr_to_cl_mem.
  4. Program Compilation — clCreateProgramWithSource() stores the OpenCL C source string. clBuildProgram() writes it to a temp file, invokes nvopencl_wrapper, reads back PTX, and calls gpgpu_ptx_sim_load_ptx_from_string().
  5. Kernel Creation — clCreateKernel(name) looks up the function_info* in pgm_info::m_kernels by kernel name.
  6. Argument Binding — Each clSetKernelArg(index, size, value) stores an arg_info in the kernel's argument map.
  7. Work Dimension Mapping — clEnqueueNDRangeKernel() computes GridDim = global_work_size / local_work_size for each of 1–3 dimensions.
  8. Kernel Launch — A kernel_info_t is created with the computed grid/block dims and enqueued via gpgpu_opencl_ptx_sim_main_perf().
  9. Simulation — The core gpgpu_sim::cycle() loop executes the kernel to completion.
  10. Synchronisation — clFinish() blocks until all enqueued operations complete on the command queue.

Work Dimension Mapping — NDRange to Grid/Block

// opencl_runtime_api.cc — clEnqueueNDRangeKernel core logic
// Map OpenCL work dimensions to CUDA grid/block dimensions
dim3 GridDim, BlockDim;

GridDim.x = global_work_size[0] / local_work_size[0];
GridDim.y = (work_dim >= 2) ? global_work_size[1] / local_work_size[1] : 1;
GridDim.z = (work_dim >= 3) ? global_work_size[2] / local_work_size[2] : 1;

BlockDim.x = local_work_size[0];
BlockDim.y = (work_dim >= 2) ? local_work_size[1] : 1;
BlockDim.z = (work_dim >= 3) ? local_work_size[2] : 1;

// Create kernel_info_t and launch
kernel_info_t *grid = new kernel_info_t(GridDim, BlockDim, entry);
gpgpu_opencl_ptx_sim_main_perf(grid);

Program Build — OpenCL Source to PTX

// _cl_program::Build() — simplified
cl_int _cl_program::Build(const char *options) {
  // 1. Write OpenCL source to temp file
  FILE *fp = fopen(src_filename, "w");
  fprintf(fp, "%s", m_pgm[device].m_source.c_str());
  fclose(fp);

  // 2. Invoke nvopencl_wrapper (NVIDIA's compiler)
  std::string cmd = "nvopencl_wrapper " + src_filename;
  if (getenv("OPENCL_REMOTE_GPU_HOST"))
    cmd = "ssh " + remote_host + " " + cmd;
  system(cmd.c_str());

  // 3. Read compiled PTX and load into simulator
  std::string ptx = read_file(ptx_filename);
  gpgpu_ptx_sim_load_ptx_from_string(ptx, source_num);
  return CL_SUCCESS;
}
