cuobjdump_to_ptxplus — CUDA Binary Disassembly Tool

PTX + ELF + SASS → PTXPlus Binary Translation

Converts NVIDIA cuobjdump output (PTX, ELF sections, and SASS disassembly) into PTXPlus format — an extended PTX that preserves native SASS instruction scheduling. This enables GPGPU-Sim to model the GPU's native ISA more accurately than pure PTX simulation.

💡 What is cuobjdump_to_ptxplus?

Analogy: Imagine a Rosetta Stone that takes three ancient scripts — PTX (the high-level virtual ISA), ELF (the binary structure), and SASS (the native machine code) — and merges them into a single enriched document (PTXPlus) that preserves the scheduling wisdom of the hardware compiler while remaining readable by the simulator. Each Lex/Yacc grammar is a specialized decoder for one of these "scripts."

🚶 Step-by-Step Narrated Walkthrough

Follow a single cuobjdump_to_ptxplus ptx.file sass.file elf.file out.ptxplus invocation:

  1. File Opening — main() opens 4 files: the PTX source, SASS disassembly, ELF binary, and the output PTXPlus file.
  2. ELF Parsing — elf_parse() uses the elf.l/elf.y grammar to extract binary section structure, identifying code and data segments.
  3. PTX Parsing — ptx_parse() uses ptx.l/ptx.y to tokenize and parse PTX instructions into cuobjdumpInst objects, building two lists: g_headerList (directives) and g_instList (instructions).
  4. Error Check — If g_error_detected is set during PTX parsing, the tool aborts with an assertion failure.
  5. Texture Mapping — g_instList→setRealTexList(g_headerList→getRealTexList()) copies texture reference names from the header directives into the instruction list for correct texture operand resolution.
  6. SASS Parsing — sass_parse() uses sass.l/sass.y to parse the native GPU assembly, attaching scheduling information and instruction ordering to the existing instruction list.
  7. Header Emission — g_headerList→printHeaderInstList() writes the //HEADER section containing PTX directives, version info, and declarations.
  8. Instruction Merging — g_instList→printCuobjdumpPtxPlusList(g_headerList) emits the //INSTRUCTIONS section, merging PTX operations with SASS-derived scheduling.
  9. Output Complete — The PTXPlus file is closed and ready for loading by the simulator via gpgpu_ptx_sim_load_ptx_from_filename().

Code Snippets

Main Driver — cuobjdump_to_ptxplus.cc

// cuobjdump_to_ptxplus.cc — main translation driver
cuobjdumpInstList *g_instList = new cuobjdumpInstList();
cuobjdumpInstList *g_headerList = new cuobjdumpInstList();

int main(int argc, char* argv[]) {
    // Usage: cuobjdump_to_ptxplus ptx sass elf ptxplus_out
    sass_in  = fopen(argv[2], "r");
    ptx_in   = fopen(argv[1], "r");
    elf_in   = fopen(argv[3], "r");
    ptxplus_out = fopen(argv[4], "w");

    elf_parse();    // Parse ELF structure
    ptx_parse();    // Parse PTX → g_instList + g_headerList
    assert(!g_error_detected);

    // Map texture references from PTX header
    g_instList->setRealTexList(g_headerList->getRealTexList());

    sass_parse();   // Parse SASS + merge scheduling

    // Emit PTXPlus output
    output("//HEADER\n");
    g_headerList->printHeaderInstList();
    output("//END HEADER\n\n\n");
    output("//INSTRUCTIONS\n");
    g_instList->printCuobjdumpPtxPlusList(g_headerList);
    output("//END INSTRUCTIONS\n");
    return 0;
}

cuobjdumpInst — Instruction Data Structure

// cuobjdumpInst.h — single instruction representation
class cuobjdumpInst {
protected:
    std::string m_label;                      // instruction label
    std::list<std::string>* m_predicate;      // predicate register
    std::string m_base;                       // mnemonic (add, mov, ld, etc.)
    std::list<std::string>* m_baseModifiers;  // .rn, .ftz, .sat, etc.
    std::list<std::string>* m_typeModifiers;  // .f32, .u64, .s16, etc.
    std::list<std::string>* m_operands;       // destination + sources
    std::list<std::string>* m_predicateModifiers;
public:
    void setBase(const char* mnemonic);
    void addOperand(const char* operand);
    void printCuobjdumpPtxPlus();  // emit in PTXPlus format
};
