Implements the router pipeline models — the heart of the NoC. Each router reads input flits, computes routes, allocates VCs and switch bandwidth, traverses the crossbar, and sends flits on output channels.

📚 What is this & why does it exist?

Every node in the network (SM or memory partition) connects to a router. The router receives flits from input channels, decides which output port to send them on, arbitrates for the crossbar switch, and forwards flits to the next hop. The routers sub-module provides three different microarchitectures: an input-queued (IQ) router for production use, a chaos router for deflection routing, and an event-driven router for latency-optimized workloads.

💡 Real-world analogy

A router is like a postal sorting facility. Packages (flits) arrive at loading docks (input ports). Workers first read the destination address (route computation), then reserve a sorting lane (VC allocation), compete for time on the conveyor belt (switch allocation), ride the belt to the correct outbound dock (crossbar traversal), and are loaded onto the next truck (output channel). The IQ router is a highly organized facility with assigned lanes; the chaos router is a looser facility where packages get deflected to any available dock if their preferred one is busy.

Code Examples

Example: IQRouter Pipeline Evaluate Cycle

void IQRouter::_InternalStep() {
  // Pipeline stages execute in reverse order to avoid combinational loops
  _InputQueuing();          // Stage flits from channels into buffers

  _RouteEvaluate();         // RC: compute output port for head flits
  _VCAllocEvaluate();       // VA: allocate output VC from Allocator
  _SWHoldEvaluate();        // SA-hold: maintain switch for multi-flit packets
  _SWAllocEvaluate();       // SA: compete for crossbar bandwidth
  _SwitchEvaluate();        // ST: traverse crossbar, enqueue to output buffer

  _RouteUpdate();           // Commit RC results
  _VCAllocUpdate();         // Commit VA results
  _SWHoldUpdate();          // Commit hold decisions
  _SWAllocUpdate();         // Commit SA results
  _SwitchUpdate();          // Commit ST results

  _OutputQueuing();         // Move flits from output buffer to channels
}

Example: Router Factory

Router *Router::NewRouter(const Configuration& config,
    Module *parent, const string & name, int id,
    int inputs, int outputs) {
  const string type = config.GetStr("router");
  if (type == "iq")    return new IQRouter(config, parent, name, id, inputs, outputs);
  if (type == "chaos") return new ChaosRouter(config, parent, name, id, inputs, outputs);
  if (type == "event") return new EventRouter(config, parent, name, id, inputs, outputs);
  cerr << "Unknown router type: " << type << endl;
  exit(-1);
}
