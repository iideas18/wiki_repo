Arbiters — Contention Resolution Mechanisms

Low-level building blocks that select exactly one winner from a set of competing requests on a single shared resource. Used by separable allocators and event-driven routers.

📚 What is this & why does it exist?

When several inputs compete for a single output port, someone has to decide who goes first. An arbiter is a tiny decision-making unit that picks one winner per resource per cycle. Allocators use arrays of arbiters (one per input port, one per output port) to decompose the global NxM matching problem into simpler 1-of-N selections.

💡 Real-world analogy

Think of a busy deli counter with one ticket dispenser. Customers pull numbered tickets (requests) and wait. The counter clerk (arbiter) calls the next number in order (round-robin), or serves the VIP customer first (priority), or consults a fairness chart that tracks who has been served least recently (matrix arbiter). The tree arbiter is like having multiple regional deli counters whose winners then compete at a master counter — a hierarchical tournament.

Round-Robin Arbitration Focus

Rotating priority pointer ensures long-term fairness. Constant-time selection with Supersedes() static helper for modular distance comparison.

Matrix & Priority Arbiter Focus

Matrix arbiter maintains an NxN priority table updated on each grant — provably fair with O(1) convergence to maximum matching. Priority arbiter serves highest-priority request with RR tie-breaking.

Extracted topic page

Hierarchical Tree Arbitration Focus

Scalable design: inputs divided into groups, each with its own sub-arbiter. Group winners compete at a global arbiter. Reduces wiring complexity from O(N) to O(√N).

Code Examples

Example: RoundRobinArbiter Arbitrate Logic

int RoundRobinArbiter::Arbitrate(int* id, int* pri) {
  // Scan from _pointer position, wrapping around
  for (int offset = 0; offset < _size; ++offset) {
    int input = (_pointer + offset) % _size;
    if (_request[input].valid) {
      _selected = input;
      if (id)  *id  = _request[input].id;
      if (pri) *pri = _request[input].pri;
      return input;
    }
  }
  return -1;  // no valid request
}

void RoundRobinArbiter::UpdateState() {
  if (_selected >= 0)
    _pointer = (_selected + 1) % _size;  // rotate past winner
}

Example: MatrixArbiter Priority Update

void MatrixArbiter::UpdateState() {
  if (_selected < 0) return;
  // Winner loses priority against all losers
  for (int i = 0; i < _size; ++i) {
    _matrix[_selected][i] = 0;  // winner demoted vs everyone
    _matrix[i][_selected] = 1;  // everyone promoted vs winner
  }
}
