What is this?

The utils package is the engine room of the AI Hedge Fund. Every agent and every runner depends on these shared primitives. Think of it as a backstage crew at a Broadway show: the LLM wrapper (call_llm) is the lighting tech who never misses a cue, the analyst registry (ANALYST_CONFIG) is the cast list, the progress tracker (AgentProgress) is the stage manager calling out scene changes on a live dashboard, and the Ollama module is the equipment truck that makes sure local hardware is powered up and ready.

    Data Flow — call_llm() Retry Pipeline

    sequenceDiagram
    participant Agent
    participant call_llm
    participant Config as get_agent_model_config
    participant LLM as LangChain Model
    participant Parse as JSON Parser

    Agent->>call_llm: prompt, pydantic_model, agent_name, state
    call_llm->>Config: extract model_name + provider
    Config-->>call_llm: ("gpt-4.1", "OPENAI")
    call_llm->>LLM: llm.with_structured_output(model)

    loop max_retries (default 3)
        call_llm->>LLM: llm.invoke(prompt)
        alt JSON mode supported
            LLM-->>call_llm: Pydantic instance
        else Fallback
            LLM-->>Parse: raw text
            Parse-->>call_llm: extract_json_from_response()
        end
        alt Success
            call_llm-->>Agent: parsed BaseModel
        else Error
            call_llm->>call_llm: retry attempt + 1
        end
    end
    call_llm-->>Agent: default_factory() or create_default_response()

    Code Examples

    Example 1 — Using call_llm() with structured output

    from pydantic import BaseModel
from src.utils.llm import call_llm

class StockSignal(BaseModel):
    signal: str        # "bullish" | "bearish" | "neutral"
    confidence: float  # 0.0 – 1.0
    reasoning: str

# Agent invocation with automatic retries and fallback
result = call_llm(
    prompt=[system_msg, human_msg],
    pydantic_model=StockSignal,
    agent_name="warren_buffett",
    state=agent_state,        # carries model config + API keys
    max_retries=3,
    default_factory=lambda: StockSignal(
        signal="neutral", confidence=0.0,
        reasoning="Error in analysis, using default"
    ),
)
print(result.signal, result.confidence)

    Example 2 — AgentProgress handler pattern

    from src.utils.progress import progress

# Register a custom handler (e.g., for SSE streaming)
@progress.register_handler
def on_update(agent_name, ticker, status, analysis, timestamp):
    event = {
        "agent": agent_name,
        "ticker": ticker,
        "status": status,
        "timestamp": timestamp,
    }
    send_sse(event)

# Agents call update_status() during execution
progress.start()
progress.update_status("warren_buffett", "AAPL", "analyzing financials")
progress.update_status("warren_buffett", "AAPL", "done", analysis="bullish 0.85")
progress.stop()

# Unregister when done
progress.unregister_handler(on_update)
