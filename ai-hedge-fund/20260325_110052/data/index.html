💡 What is this?

Picture a filing cabinet with color-coded folders. Each folder type (Price, FinancialMetrics, InsiderTrade, etc.) has a strict template — every document inside must have exactly the right fields. The Cache class is the desk tray on top: recently-used documents sit there for instant re-access instead of pulling from the API drawer every time. New documents are merged and deduplicated automatically via a key field (e.g., time for prices, report_period for metrics).

    Code Examples

    Example 1 — Using Cache Directly

    from src.data.cache import get_cache

cache = get_cache()

# Store price data
cache.set_prices("AAPL_2025-01-01_2025-06-01", [
    {"open": 150.0, "close": 152.5, "high": 153.0,
     "low": 149.5, "volume": 80000000, "time": "2025-01-02"},
    {"open": 152.5, "close": 151.0, "high": 154.0,
     "low": 150.0, "volume": 75000000, "time": "2025-01-03"},
])

# Retrieve — returns list[dict] or None
cached = cache.get_prices("AAPL_2025-01-01_2025-06-01")
print(len(cached))  # 2

# Adding overlapping data — dedup by 'time'
cache.set_prices("AAPL_2025-01-01_2025-06-01", [
    {"open": 152.5, "close": 151.0, "high": 154.0,
     "low": 150.0, "volume": 75000000, "time": "2025-01-03"},  # duplicate
    {"open": 151.0, "close": 155.0, "high": 156.0,
     "low": 150.5, "volume": 90000000, "time": "2025-01-06"},  # new
])
print(len(cache.get_prices("AAPL_2025-01-01_2025-06-01")))  # 3

    from src.data.models import FinancialMetrics

# FinancialMetrics groups ~40 fields into categories:

# Leverage:   debt_to_equity, debt_to_assets, interest_coverage
# Growth:     revenue, earnings, book_value, EPS, FCF, operating_income, EBITDA growth
# Per-share:  EPS, book_value_per_share, FCF_per_share, payout_ratio

m = FinancialMetrics(ticker="AAPL", report_period="2025-03-31",
                     period="ttm", currency="USD", market_cap=3.2e12)
print(m.market_cap)  # 3200000000000.0
