✈️ What is this?

Think of the backtesting module as a flight simulator for trading. Just as pilots rehearse instrument failures and turbulence in a simulator before flying real passengers, this engine replays historical market data day-by-day, lets AI analyst agents make buy/sell/short/cover decisions, executes those trades against a virtual portfolio, and scores the outcome with industry-standard risk metrics — all without risking a single real dollar.

    Deep Dive

    Portfolio Management (Long / Short / Margin)

    The Portfolio class maintains a PortfolioSnapshot dict containing cash, margin state, per-ticker positions, and realized gains. Four mutation methods handle the trade lifecycle:

    • apply_long_buy — deducts cash, updates weighted-average cost basis. If cash is insufficient, buys the maximum affordable quantity.
    • apply_long_sell — realizes gain/loss (price − avg_cost) × qty, credits cash, resets cost basis when position hits zero.
    • apply_short_open — requires margin proceeds × margin_requirement. Credits short proceeds, debits margin. Falls back to maximum affordable quantity.
    • apply_short_cover — buys-to-cover, realizes (avg_short_price − price) × qty, releases proportional margin.

    All methods return the actually executed quantity (which may be less than requested).

    Performance Metrics (Sharpe / Sortino / Drawdown)

    PerformanceMetricsCalculator takes the equity curve (list[PortfolioValuePoint]) and computes:

    • Sharpe Ratio — √252 × mean(excess) / std(excess) where excess = daily_return − daily_rf. Default risk-free rate: 4.34 % annual.
    • Sortino Ratio — same numerator but denominator uses downside deviation √mean(min(excess,0)²). Returns ∞ when positive mean but zero downside.
    • Max Drawdown — percentage peak-to-trough loss from cumulative maximum. Reports the date of the worst drawdown.

    Metrics are computed only after 3+ data points to avoid noisy early results.

    Trade Execution & Agent Loop

    TradeExecutor.execute_trade is a lightweight dispatcher: it coerces the action string into the Action enum then routes to the corresponding Portfolio.apply_* method. AgentController.run_agent wraps the AI agent callable, converts the Portfolio to a plain snapshot dict (for legacy compatibility), and normalizes every ticker's decision to ensure action and quantity keys always exist — defaulting to hold / 0.

    Portfolio.apply_long_buy — weighted average cost basis

    def apply_long_buy(self, ticker: str, quantity: int, price: float) -> int:
    if quantity <= 0:
        return 0
    position = self._portfolio["positions"][ticker]
    cost = quantity * price
    if cost <= self._portfolio["cash"]:
        old_shares = position["long"]
        old_cost_basis = position["long_cost_basis"]
        total_shares = old_shares + quantity
        if total_shares > 0:
            total_old_cost = old_cost_basis * old_shares
            position["long_cost_basis"] = (total_old_cost + cost) / total_shares
        position["long"] = total_shares
        self._portfolio["cash"] -= cost
        return quantity
    # Fallback: buy as many shares as cash allows
    max_qty = int(self._portfolio["cash"] / price) if price > 0 else 0
    if max_qty > 0:
        return self.apply_long_buy(ticker, max_qty, price)  # recurse once
    return 0

    PerformanceMetricsCalculator.compute_metrics — Sharpe & Sortino

    def compute_metrics(self, values):
    df = pd.DataFrame(values).set_index("Date")
    df["Daily Return"] = df["Portfolio Value"].pct_change()
    clean = df["Daily Return"].dropna()
    if len(clean) < 2:
        return {"sharpe_ratio": None, "sortino_ratio": None, "max_drawdown": None}

    daily_rf = self.annual_rf_rate / self.annual_trading_days   # 0.0434 / 252
    excess = clean - daily_rf
    mean_ex, std_ex = excess.mean(), excess.std()

    sharpe = float(np.sqrt(252) * mean_ex / std_ex) if std_ex > 1e-12 else 0.0

    downside = np.minimum(excess, 0)
    dd_dev = float(np.sqrt(np.mean(downside**2)))
    sortino = float(np.sqrt(252) * mean_ex / dd_dev) if dd_dev > 1e-12 else (
        float("inf") if mean_ex > 0 else 0.0
    )

    rolling_max = df["Portfolio Value"].cummax()
    drawdown = (df["Portfolio Value"] - rolling_max) / rolling_max
    max_dd = float(drawdown.min() * 100)
    return {"sharpe_ratio": sharpe, "sortino_ratio": sortino, "max_drawdown": max_dd}

    TradeExecutor.execute_trade — action dispatch

    class TradeExecutor:
    def execute_trade(self, ticker, action, quantity, current_price, portfolio):
        if quantity is None or quantity <= 0:
            return 0
        action_enum = Action(action)  # coerce string → enum
        if action_enum == Action.BUY:
            return portfolio.apply_long_buy(ticker, int(quantity), float(current_price))
        if action_enum == Action.SELL:
            return portfolio.apply_long_sell(ticker, int(quantity), float(current_price))
        if action_enum == Action.SHORT:
            return portfolio.apply_short_open(ticker, int(quantity), float(current_price))
        if action_enum == Action.COVER:
            return portfolio.apply_short_cover(ticker, int(quantity), float(current_price))
        return 0  # hold
