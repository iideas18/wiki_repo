💡 What is this & why does it exist?
Think of this module as a virtual investment committee. Just as a real hedge fund seats analysts around a table — each with a different specialty (value, growth, macro, technicals) — this code creates 20 software analysts that independently evaluate every ticker. Each agent embodies a distinct investing philosophy (Ben Graham's margin-of-safety, Cathie Wood's disruptive innovation, Michael Burry's deep-value contrarianism) and produces a structured bullish / bearish / neutral signal with confidence. The portfolio manager then synthesises all signals into a final trade decision, exactly as a human PM would weigh competing opinions before sizing a position.

Architecture — Agent Type Hierarchy

All agents share a common function signature accepting AgentState and returning a signal dict. They fall into three tiers: value-oriented persona agents, growth/momentum agents, and quantitative engines. Two management agents (Risk & Portfolio) sit on top.

Data Flow — Signal Generation Pipeline

Each agent follows a four-step pipeline: receive state → fetch financial data → score/analyse → return signal. LLM-enhanced agents add a fifth step where quantitative results are narrated through an investor persona prompt.

sequenceDiagram
    participant G as LangGraph
    participant A as Agent Function
    participant API as Financial Data API
    participant LLM as LLM (Optional)
    participant S as AgentState

    G->>A: invoke(state, agent_id)
    A->>S: read tickers, end_date, portfolio
    loop For each ticker
        A->>API: get_financial_metrics(ticker)
        A->>API: search_line_items(ticker)
        A->>API: get_insider_trades / get_prices
        API-->>A: raw data
        A->>A: score sub-components
        opt LLM-enhanced agent
            A->>LLM: prompt(philosophy + analysis_data)
            LLM-->>A: SignalModel(signal, confidence, reasoning)
        end
    end
    A->>S: state.data.analyst_signals[agent_id] = signals
    A-->>G: return messages + data

Deep Dive — Scoring & Signal Generation Patterns

Pattern 1 — Threshold-Based Scoring

Used by most persona agents (Graham, Damodaran, Ackman, Burry, Pabrai). Each sub-analysis awards integer points; the total is compared against max_score:

  • ≥ 70% of max → bullish
  • ≤ 30% of max → bearish
  • Otherwise → neutral

Confidence is scaled as (score / max_score) × 100, clamped to 0–100.

Pattern 2 — Weighted Factor Scoring

Used by quantitative agents (Growth, Technical, Valuation). Each factor produces a 0–1 score multiplied by its weight. The weighted sum determines the signal:

  • Growth agent: >0.6 bullish, <0.4 bearish
  • Technical analyst: >0.2 bullish, <-0.2 bearish (normalised to ±1)
  • Valuation: gap-based — >15% undervalued = bullish

Pattern 3 — Margin-of-Safety DCF

Agents like Damodaran, Buffett, and Ackman compute intrinsic value via DCF, then compare to market cap:

margin_of_safety = (intrinsic_value - market_cap) / market_cap

# Thresholds vary by agent philosophy:
# Damodaran: >= 25% bullish, <= -25% bearish
# Ackman:    >= 30% bullish
# Buffett:   >= 25% bullish (owner earnings basis)
# Pabrai:    composite score >= 7.5/10 bullish

Pattern 4 — Ensemble Combination

The technical analyst runs five independent sub-strategies and combines them with fixed weights. The portfolio manager then ensembles all agent signals, applying risk limits from the risk manager before issuing the final trade.

def ben_graham_agent(state: AgentState, agent_id: str = "ben_graham_agent"):
    """Analyst agent inspired by Benjamin Graham's value investing."""
    data = state["data"]
    end_date = data["end_date"]
    tickers = data["tickers"]

    analysis_data = {}
    agent_signals = {}

    for ticker in tickers:
        progress.update_status(agent_id, ticker, "Analyzing")
        # ... quantitative scoring ...
        signal_result = generate_graham_output(
            ticker, analysis_data[ticker], agent_id, state
        )
        agent_signals[ticker] = signal_result

    message = HumanMessage(content=json.dumps(agent_signals), name=agent_id)
    if state["metadata"]["show_reasoning"]:
        show_agent_reasoning(agent_signals, "Ben Graham Agent")

    state["data"]["analyst_signals"][agent_id] = agent_signals
    progress.update_status(agent_id, None, "Done")
    return {"messages": [message], "data": state["data"]}

from pydantic import BaseModel
from typing import Literal

class BenGrahamSignal(BaseModel):
    signal: Literal["bullish", "bearish", "neutral"]
    confidence: float
    reasoning: str

# LLM call returns structured output:
result = call_llm(
    prompt=template.invoke({"analysis_data": json.dumps(analysis)}),
    pydantic_model=BenGrahamSignal,
    agent_name=agent_id,
    state=state,
