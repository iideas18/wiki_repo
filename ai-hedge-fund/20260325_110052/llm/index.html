💡 What is this?

Imagine a universal remote control that can operate 13 different TV brands. You pick the brand (provider) and model number, and the remote handles the protocol differences behind the scenes. This module is exactly that: get_model() takes a model name and provider, resolves the correct API key from the environment or an explicit dict, and returns a ready-to-use LangChain chat model — whether it's OpenAI, Anthropic, Google, Ollama, or any of 9 more.

    Code Examples

    Example 1 — Using get_model() Factory

    from src.llm.models import get_model, ModelProvider

# Get an OpenAI model instance
llm = get_model("gpt-4.1", ModelProvider.OPENAI)

# Or pass explicit API keys (useful in web API mode)
llm = get_model(
    "claude-sonnet-4-20250514",
    ModelProvider.ANTHROPIC,
    api_keys={"ANTHROPIC_API_KEY": "sk-ant-..."}
)

# Invoke
response = llm.invoke("Analyze AAPL fundamentals")
print(response.content)

    Example 2 — Checking JSON Mode Support

    from src.llm.models import find_model_by_name

model = find_model_by_name("deepseek-chat")
if model and not model.has_json_mode():
    # DeepSeek doesn't support JSON mode;
    # fall back to text parsing with regex
    print("Using text output mode for", model.display_name)
else:
    # Safe to request structured JSON
    print("JSON mode available")
