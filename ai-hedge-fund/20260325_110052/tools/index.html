💡 What is this?

Think of this module as the research assistant who goes to the library (Financial Datasets API) to fetch specific reports. Before each trip, the assistant checks a local desk cache — if the report is already there, great. If not, they walk to the library, but if the librarian says "too many requests" (HTTP 429), the assistant waits patiently with increasing delays (60 s → 90 s → 120 s) before trying again. Some reports (insider trades, news) may span multiple pages, so the assistant keeps fetching until all pages are collected.

    Pagination Strategy

    flowchart TD
  START[Call get_insider_trades / get_company_news] --> FETCH[Fetch page with filing_date_lte]
  FETCH --> CHECK{Got full page?}
  CHECK -->|No or no start_date| DONE[Return all_trades]
  CHECK -->|Yes + has start_date| UPDATE[Set current_end_date = min filing_date]
  UPDATE --> PAST{Reached start_date?}
  PAST -->|Yes| DONE
  PAST -->|No| FETCH

    Functions get_insider_trades() and get_company_news() use cursor-style pagination: they shift current_end_date to the oldest item's date in each batch, continuing until the batch is incomplete or start_date is reached.

    Code Examples

    Example 1 — Fetching Prices with Caching

    from src.tools.api import get_prices

# First call → API request, cached
prices = get_prices("AAPL", "2025-01-01", "2025-06-01")
print(f"Got {len(prices)} daily bars")
print(f"Latest close: ${prices[-1].close}")

# Second call → cache hit, no network
prices_again = get_prices("AAPL", "2025-01-01", "2025-06-01")
assert len(prices_again) == len(prices)  # Same data from cache

    Example 2 — Searching Arbitrary Line Items

    from src.tools.api import search_line_items

# POST-based search for specific financial statement fields
items = search_line_items(
    ticker="MSFT",
    line_items=["revenue", "net_income", "free_cash_flow"],
    end_date="2025-03-31",
    period="ttm",
    limit=4,
)
for item in items:
    # LineItem uses extra="allow" — dynamic fields
    print(f"{item.report_period}: revenue={getattr(item, 'revenue', 'N/A')}")

    Example 3 — Paginated Insider Trades

    from src.tools.api import get_insider_trades

# Fetches ALL insider trades between dates via pagination
trades = get_insider_trades(
    ticker="NVDA",
    end_date="2025-06-01",
    start_date="2024-01-01",
    limit=100,  # per-page limit
)
print(f"Total trades: {len(trades)}")
for t in trades[:3]:
    print(f"  {t.filing_date}: {t.name} {'bought' if (t.transaction_shares or 0) > 0 else 'sold'}"
          f" ${abs(t.transaction_value or 0):,.0f}")
