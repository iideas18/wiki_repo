AI Hedge Fund

Multi-Agent Investment Decision System

An AI-powered hedge fund that employs 18+ specialized analyst agents — each modeled after legendary investors like Warren Buffett, Ben Graham, and Cathie Wood — to collaboratively analyze stocks, manage risk, and produce trading decisions. Built with LangGraph for orchestration, FastAPI for the web backend, and React Flow for visual workflow editing.

🤖 20 Analyst Agents 📈 LangGraph Orchestration 💻 Full-Stack Web App ⚠️ Educational Only

📚 What is this & why does it exist?

AI Hedge Fund is a proof-of-concept system that uses multiple AI agents to make collaborative stock trading decisions. Each agent embodies a different investing philosophy — from deep value (Ben Graham) to disruptive growth (Cathie Wood) — and generates buy/sell/hold signals with confidence scores. A portfolio manager agent synthesizes all signals under risk constraints to produce final trading orders. The system supports both single-run analysis and historical backtesting with performance metrics like Sharpe ratio and max drawdown.

💡 Real-world analogy

Imagine a Wall Street investment committee meeting: around the table sit 18 analysts, each with a different specialty — one reads only balance sheets, another tracks insider trades, a third watches price charts. They each write down their recommendation on a card (buy, sell, or hold) with a confidence percentage. The risk manager then checks the portfolio’s current exposure and sets position limits. Finally, the portfolio manager reads all the cards, weighs the consensus, and places the actual orders — but only within the limits the risk manager set. That’s exactly what this system does, except the analysts are LLM-powered agents and the meeting happens in a LangGraph workflow.

🚶 Step-by-Step Narrated Walkthrough

Follow a single stock analysis request for AAPL as it flows through the entire system:

  1. User Input (CLI/Web) — The user selects ticker AAPL, picks 5 analysts (Buffett, Graham, Technicals, Sentiment, Valuation), and chooses GPT-4o as the LLM model.
  2. Workflow Creation — create_workflow() builds a LangGraph StateGraph with nodes for each selected analyst, plus risk_manager and portfolio_manager. Edges connect analysts → risk → portfolio.
  3. State Initialization — AgentState is populated with tickers, date range, portfolio snapshot (cash: $100k, no positions), and model configuration.
  4. Parallel Agent Execution — All 5 analyst agents run concurrently. Each fetches financial data via src/tools/api.py (with caching in src/data/cache.py).
  5. Warren Buffett Agent — Analyzes AAPL’s moat (ROE > 15%), earnings consistency (10 quarters), management quality, and calculates intrinsic value using owner earnings DCF. Returns: bullish, 82% confidence.
  6. Ben Graham Agent — Computes Graham Number (sqrt(22.5 × EPS × BVPS)), checks net-net value (NCAV), current ratio ≥ 2, debt ratio. Returns: neutral, 55% confidence.
  7. Technical Analyst — Calculates EMA crossovers (8/21/55), RSI, Bollinger Bands, ADX, Hurst exponent. Ensemble-weights 5 strategies (trend 25%, momentum 25%, mean reversion 20%, volatility 15%, stat arb 15%). Returns: bullish, 68% confidence.
  8. Sentiment Analyst — Fetches insider trades (30% weight) and news articles (70% weight). LLM classifies top 5 articles. Aggregates with weighted voting. Returns: bullish, 71% confidence.
  9. Valuation Analyst — Runs 4 valuation methods: DCF (35%), Owner Earnings (35%), EV/EBITDA (20%), Residual Income (10%). Probability-weights bear/base/bull scenarios. Returns: neutral, 60% confidence.
  10. Risk Manager — Calculates 60-day rolling volatility (annualized), percentile rank, and cross-ticker correlation. Sets position limit to 20% of portfolio ($20k) adjusted by volatility multiplier.
  11. Portfolio Manager — Receives 5 signals (3 bullish, 2 neutral) plus risk limits. LLM prompt constrains decisions to allowed actions (buy up to 100 shares at $195). Decides: buy 50 shares AAPL, confidence 75%.
  12. Output Display — Results shown as a formatted table with per-agent signals, final decision, and portfolio summary. In backtest mode, this repeats daily across the date range.
