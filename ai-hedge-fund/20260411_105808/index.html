🎯 Project Philosophy

When you first look at this codebase, the most striking design choice is the ensemble of independent analyst agents, each modeled after a real-world investor with a distinct philosophy. This isn't just a gimmick — it reflects a deep insight about investing: no single strategy works in all market conditions. By running Warren Buffett's value analysis alongside Nassim Taleb's tail-risk assessment and a technical momentum strategy simultaneously, the system captures diverse perspectives that a monolithic algorithm would miss.

The project prioritizes correctness and interpretability over speed. Each agent produces not just a signal (bullish/bearish/neutral) but also a confidence score and detailed reasoning. The portfolio manager sees all 19 opinions before making a decision. This transparency — knowing why the system recommends buying or selling — is more valuable than a black-box prediction.

The architecture follows a strict separation of concerns: analysts analyze (they don't trade), the risk manager sets position limits (it doesn't pick stocks), and the portfolio manager makes final decisions (it doesn't analyze fundamentals). This pipeline mirrors how real institutional trading desks operate, with research analysts, risk officers, and portfolio managers each having clearly defined responsibilities.

Perhaps most importantly, this is an educational project — designed to teach how AI can be applied to finance, not to be deployed with real money. The code is deliberately readable, well-structured, and thoroughly documented through its agent prompts.

Core Trading Engine

🤖 AI Analyst Agents

19 investment philosophies as autonomous LLM-powered analysts

The intellectual core of the system. 13 investor-inspired agents (Buffett, Graham, Taleb, etc.) and 6 quantitative agents analyze stocks from diverse perspectives, producing independent buy/sell/hold signals with confidence scores and reasoning.

21 files~8.5K LOC19 strategies

📈 Backtesting Engine

Historical simulation with portfolio tracking and performance metrics

Replays the full agent ensemble over historical date ranges, executing trades on a simulated portfolio. Computes Sharpe ratio, Sortino ratio, max drawdown, and benchmarks against S&P 500.

10 files~1.8K LOCLong/Short support

Infrastructure

📦 Data & Orchestration

Financial API client, caching, LangGraph state, LLM provider abstraction

The connective tissue: fetches financial data from external APIs with caching, manages shared agent state via LangGraph, and abstracts 13 LLM providers behind a single factory function. Every agent depends on this layer.

9 files~2.2K LOC5 API endpoints

🌐 Web Application

FastAPI backend with SSE streaming and React node-graph UI

Visual interface for composing agent pipelines via a node graph editor. Supports real-time progress streaming via Server-Sent Events, flow persistence in SQLite, and per-agent model selection.

20+ files~3.5K LOCREST + SSE

How Agents & Risk/Portfolio Connect

The critical hand-off between the analysis phase and the decision phase. Agents produce signals independently; risk and portfolio management apply constraints deterministically before the final LLM-powered decision.

sequenceDiagram
    participant A1 as Warren Buffett Agent
    participant A2 as Technical Analyst
    participant A3 as Nassim Taleb Agent
    participant BUS as AgentState Bus
    participant RISK as Risk Manager
    participant PM as Portfolio Manager

    A1->>BUS: signal=bullish, confidence=75, reasoning=...
    A2->>BUS: signal=bearish, confidence=60, reasoning=...
    A3->>BUS: signal=neutral, confidence=40, reasoning=...
    Note over BUS: All 19 signals merged via merge_dicts
    BUS->>RISK: All analyst signals + portfolio state
    Note over RISK: Compute volatility per ticker
    Note over RISK: Compute cross-ticker correlation
    Note over RISK: Calculate position limits
    RISK->>BUS: remaining_position_limit per ticker
    BUS->>PM: Signals + limits + portfolio
    Note over PM: Pre-compute allowed actions deterministically
    Note over PM: Pure holds sent without LLM call
    PM->>PM: LLM decides action + quantity for tradable tickers
    PM->>BUS: Final decisions: {action, quantity, confidence, reasoning}
Key insight: Analyst agents own the what (bullish or bearish?). The risk manager owns the how much (position sizing). The portfolio manager owns the when and whether (final trade execution). This three-stage separation prevents any single component from having unchecked authority over trading decisions.

Build & Tech Stack

Language & Runtime

Python 3.11+ with type hints. React + TypeScript for the frontend.

AI / LLM Framework

LangGraph for agent orchestration, LangChain for LLM abstraction. Supports OpenAI, Anthropic, Google, Groq, DeepSeek, Ollama, and 7 more providers.

Data & Analysis

pandas + numpy for technical analysis. Pydantic v2 for data validation. Financial data from financialdatasets.ai API.

Web Stack

FastAPI with Server-Sent Events. SQLite via SQLAlchemy + Alembic migrations. React Flow for visual node graph editor.

Package Management

Poetry for Python dependencies. npm for frontend. Docker support included.

CLI & Display

questionary for interactive prompts. colorama + tabulate for formatted terminal output.
