If the 13 investor-inspired agents are a board of philosophers — each interpreting the same data through their personal worldview — then the 6 quantitative agents are a team of mathematicians. They don't care about Warren Buffett's opinion on moats or Taleb's views on tail risk. They compute. RSI, MACD, Bollinger Bands, Hurst exponent, P/E ratios, DCF models, growth rates, insider trading patterns. One of them — the Technical Analyst — doesn't even use an LLM. It's pure math: five strategies, weighted combination, final signal. No opinions, just numbers.

Price data retrieval. The Technical Analyst needs only price and volume data — no financial statements, no earnings, no balance sheets. This makes it the fastest data-fetching agent. 
def technical_analyst_agent(state: AgentState) -> dict:

    start_date = state["start_date"]

    analyst_signals = {}

    for ticker in tickers:

Strategy 1 — Trend Following (weight: 0.25). Uses EMA crossover (8-period vs 21-period) to detect trend direction. When short EMA crosses above long EMA, it's bullish. 
def compute_trend_signal(closes):
    ema_short = compute_ema(closes, period=8)
    ema_long = compute_ema(closes, period=21)
    # Positive when short-term momentum exceeds long-term
    crossover = (ema_short[-1] - ema_long[-1]) / ema_long[-1]
    return max(-1, min(1, crossover * 10))  # Scale and clamp
Strategy 2 — Mean Reversion (weight: 0.20). Uses Bollinger Bands to detect overbought/oversold conditions. Price below lower band suggests mean reversion upward. 
def compute_mean_reversion(closes, window=20, num_std=2):
    sma = sum(closes[-window:]) / window
    std = (sum((c - sma)**2 for c in closes[-window:]) / window) ** 0.5
    upper_band = sma + num_std * std
    lower_band = sma - num_std * std
    current = closes[-1]

    if current < lower_band:
        return 1.0   # Oversold — expect reversion up
    elif current > upper_band:
        return -1.0  # Overbought — expect reversion down
    else:
        # Linear interpolation within bands
        return -2 * (current - lower_band) / (upper_band - lower_band) + 1
Strategy 3 — Momentum (weight: 0.25). Combines RSI (Relative Strength Index) and MACD (Moving Average Convergence Divergence) for a composite momentum score. 
def compute_momentum_signal(closes):
    rsi = compute_rsi(closes, period=14)
    macd_line, signal_line = compute_macd(closes)

    # RSI component: oversold (<30) = bullish, overbought (>70) = bearish
    rsi_score = (50 - rsi) / 50  # Maps [0,100] to [1,-1]

    # MACD component: positive histogram = bullish
    macd_hist = macd_line - signal_line
    macd_score = max(-1, min(1, macd_hist / abs(signal_line) if signal_line else 0))

    return 0.5 * rsi_score + 0.5 * macd_score
Strategy 4 — Volatility (weight: 0.15). Uses ADX (Average Directional Index) to measure trend strength and ATR (Average True Range) for volatility-adjusted sizing signals. 
def compute_volatility_signal(closes, highs, lows):
    adx = compute_adx(highs, lows, closes, period=14)
    atr = compute_atr(highs, lows, closes, period=14)
    atr_pct = atr / closes[-1]  # ATR as % of price

    # Strong trend (ADX > 25) + low vol = bullish trend confidence
    # Weak trend (ADX < 20) + high vol = uncertainty
    if adx > 25 and atr_pct < 0.03:
        return 0.5   # Strong trend, contained volatility
    elif adx < 20 and atr_pct > 0.05:
        return -0.5  # Directionless, high volatility
    return 0.0
Strategy 5 — Statistical Arbitrage (weight: 0.15). Computes the Hurst exponent to determine if the price series is mean-reverting, trending, or random. 
def compute_stat_arb_signal(closes):
    hurst = compute_hurst_exponent(closes, max_lag=20)

    if hurst < 0.4:
        # Mean-reverting: use reversion signal
        return compute_mean_reversion(closes) * 0.8
    elif hurst > 0.6:
        # Trending: use momentum signal
        return compute_trend_signal(closes) * 0.8
    else:
        # Random walk: no edge
        return 0.0
Weighted combination. All 5 strategy scores are combined using pre-defined weights. The final score is mapped to the standard signal format without any LLM involvement. 
        strategies = {
            "trend": (compute_trend_signal(closes), 0.25),
            "reversion": (compute_mean_reversion(closes), 0.20),
            "momentum": (compute_momentum_signal(closes), 0.25),
            "volatility": (compute_volatility_signal(closes, highs, lows), 0.15),
            "stat_arb": (compute_stat_arb_signal(closes), 0.15),
        }

        final_score = sum(score * weight for score, weight in strategies.values())

        # Map to signal format
        if final_score > 0.2:
            signal = "bullish"
        elif final_score < -0.2:
            signal = "bearish"
        else:
            signal = "neutral"

        confidence = min(100, int(abs(final_score) * 100))
        reasoning = "; ".join(f"{k}: {v[0]:.2f}" for k, v in strategies.items())

        analyst_signals[ticker] = {
            "signal": signal,
            "confidence": confidence,
            "reasoning": reasoning
        }

Design Rationale

Why the Technical Analyst Uses No LLM

The Technical Analyst is the only agent in the system that produces signals through pure computation. This is not an oversight — it's a deliberate design choice based on three observations:

1. Technical analysis is entirely mathematical. RSI, MACD, Bollinger Bands, and ADX are well-defined mathematical formulas. An LLM adds zero information to a deterministic calculation. It would only add latency (3-8 seconds) and cost (API tokens) for no analytical benefit.

2. Reproducibility. A pure-computation agent produces identical results given identical inputs. This makes it invaluable for debugging and backtesting. If the Technical Analyst produces a different signal for the same data, there's a bug in the code — full stop. No need to worry about LLM temperature or prompt sensitivity.

3. Speed advantage. Without an LLM call, the Technical Analyst consistently finishes in under 500ms. In the fan-out architecture, this means its signal is always available first, providing an early read while other agents wait for LLM responses.

Why Separate Quantitative Agents from Investors

The quantitative agents could theoretically be folded into the investor category — after all, some investor agents also compute ratios. The separation exists because the quantitative agents have no investment philosophy. The Fundamentals Analyst doesn't care whether Graham or Buffett would approve of a P/E ratio of 25. It simply measures it, compares it to sector averages, and scores it. The LLM's role (when used) is synthesis, not philosophy.

Algorithm Deep-Dives

Hurst Exponent — Rescaled Range Analysis

The Hurst exponent (H) characterizes the long-term memory of a time series. It's the foundation of the statistical arbitrage sub-strategy:

  • H < 0.5: Mean-reverting — price tends to return to the mean. Favor mean reversion strategies.
  • H = 0.5: Random walk — no predictable pattern. No trading edge.
  • H > 0.5: Trending — momentum tends to persist. Favor trend-following strategies.
def compute_hurst_exponent(prices, max_lag=20):
    """Rescaled Range (R/S) analysis.

    The key insight: if log(R/S) scales linearly with log(lag),
    the slope gives us the Hurst exponent.
    """
    returns = [prices[i]/prices[i-1] - 1 for i in range(1, len(prices))]
    lags = range(2, min(max_lag, len(returns) // 2))
    log_lags, log_rs = [], []

    for lag in lags:
        chunks = [returns[i:i+lag] for i in range(0, len(returns)-lag, lag)]
        rs_values = []
        for chunk in chunks:
            if len(chunk) < 2:
                continue
            mean = sum(chunk) / len(chunk)
            cumdev = []
            running = 0
            for val in chunk:
                running += (val - mean)
                cumdev.append(running)
            R = max(cumdev) - min(cumdev)
            S = (sum((v - mean)**2 for v in chunk) / (len(chunk)-1)) ** 0.5
            if S > 1e-10:
                rs_values.append(R / S)
        if rs_values:
            import math
            log_lags.append(math.log(lag))
            log_rs.append(math.log(sum(rs_values)/len(rs_values)))

    # Linear regression: slope = Hurst exponent
    if len(log_lags) < 2:
        return 0.5  # Not enough data; assume random walk
    n = len(log_lags)
    sx = sum(log_lags)
    sy = sum(log_rs)
    sxy = sum(x*y for x,y in zip(log_lags, log_rs))
    sxx = sum(x*x for x in log_lags)
    slope = (n * sxy - sx * sy) / (n * sxx - sx * sx)
    return slope

ADX — Average Directional Index

ADX measures trend strength regardless of direction. Values above 25 indicate a strong trend; below 20 indicates a range-bound market. The Technical Analyst uses this to decide whether to trust trend-following or mean-reversion signals.

def compute_adx(highs, lows, closes, period=14):
    """Compute ADX from directional movement indicators."""
    plus_dm, minus_dm, tr_list = [], [], []
    for i in range(1, len(closes)):
        high_diff = highs[i] - highs[i-1]
        low_diff = lows[i-1] - lows[i]
        plus_dm.append(high_diff if high_diff > low_diff and high_diff > 0 else 0)
        minus_dm.append(low_diff if low_diff > high_diff and low_diff > 0 else 0)
        tr = max(highs[i] - lows[i],
                 abs(highs[i] - closes[i-1]),
                 abs(lows[i] - closes[i-1]))
        tr_list.append(tr)

    # Smoothed averages (Wilder's smoothing)
    atr = wilder_smooth(tr_list, period)
    plus_di = [100 * d / a if a > 0 else 0
               for d, a in zip(wilder_smooth(plus_dm, period), atr)]
    minus_di = [100 * d / a if a > 0 else 0
                for d, a in zip(wilder_smooth(minus_dm, period), atr)]

    # DX and ADX
    dx = [100 * abs(p - m) / (p + m) if (p + m) > 0 else 0
          for p, m in zip(plus_di, minus_di)]
    adx = wilder_smooth(dx, period)
    return adx[-1] if adx else 0

Bollinger Bands — Dynamic Support and Resistance

Bollinger Bands create an envelope around a moving average using standard deviations. The mean reversion strategy uses these as dynamic overbought/oversold thresholds.

def compute_bollinger_bands(closes, window=20, num_std=2):
    """Returns (upper_band, middle_band, lower_band, bandwidth)."""
    sma = sum(closes[-window:]) / window
    variance = sum((c - sma)**2 for c in closes[-window:]) / window
    std = variance ** 0.5
    upper = sma + num_std * std
    lower = sma - num_std * std
    bandwidth = (upper - lower) / sma  # Normalized bandwidth
    return upper, sma, lower, bandwidth
