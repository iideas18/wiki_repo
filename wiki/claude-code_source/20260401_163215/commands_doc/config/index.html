commands/config/ — Configuration Management Commands

Interactive settings panel for all Claude Code preferences

The /config command opens a full-screen React (Ink) panel with 38+ settings spanning models, themes, permissions, output styles, notifications, and more. Settings are searchable, navigable by keyboard, and changes revert on Escape.

📚 What is this & why does it exist?

The config module is the single entry point for viewing and editing every user-facing preference in Claude Code. Instead of requiring manual JSON editing, it provides an interactive terminal UI with search, arrow-key navigation, toggle switches, and sub-panels for complex settings like model selection and theme picking. All changes are persisted across three storage layers (global config, per-source settings, and session AppState) with full revert-on-cancel support.

💡 Real-world analogy

Think of the /config panel like the Settings app on your smartphone. It has categories (Display, Sound, Privacy) just like the config panel has groups (Behavior, Models, Output). Each setting is either a toggle switch or a picker that opens a sub-screen—exactly like tapping "Ringtone" opens a list. The search bar at the top lets you find any setting instantly, and pressing the back button discards unsaved changes—just like hitting Escape in the config panel triggers revertChanges().

Example 2: Model Change Handler with Analytics

// config.tsx — onChangeMainModelConfig (simplified)
function onChangeMainModelConfig(value: string | null): void {
  const previousModel = mainLoopModel

  // Track model change analytics
  logEvent('tengu_config_model_changed', {
    from_model: previousModel,
    to_model: value,
  })

  // Update session state
  setAppState(prev => ({
    ...prev,
    mainLoopModel: value,
    mainLoopModelForSession: null,
  }))

  // Record change for summary display
  const displayName = modelDisplayString(value)
  const billingNote = isBilledAsExtraUsage(value, currentPlan)
    ? ' · Billed as extra usage'
    : ''
  setChanges(prev => ({ ...prev, model: displayName + billingNote }))
}

Example 3: Revert on Escape (Snapshot Restore)

// config.tsx — revertChanges
function revertChanges(): void {
  if (!isDirty.current) return

  // Restore all snapshots taken at panel open
  saveGlobalConfig(() => initialConfig.current)
  setGlobalConfig(initialConfig.current)
  setCurrentOutputStyle(initialOutputStyle.current)
  setCurrentLanguage(initialLanguage.current)
  setTheme(initialThemeSetting.current)

  // Restore per-source settings
  updateSettingsForSource('localSettings', initialLocalSettings)
  updateSettingsForSource('userSettings', initialUserSettings)

  // Restore session state
  setAppState(initialAppState)
  setUserMsgOptIn(initialUserMsgOptIn)

  // Clear change tracking
  setChanges({})
}
