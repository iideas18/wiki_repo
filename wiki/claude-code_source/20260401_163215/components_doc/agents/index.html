components/agents/ — Agent UI Components

UI components for multi-agent workflows and agent management

The agents module provides the complete user interface for creating, viewing, editing, and deleting custom agents. It includes a multi-step creation wizard, property editors (tools, color, model), agent listing with source grouping, AI-powered agent generation, and comprehensive validation.

📚 What is this & why does it exist?

The agents UI module lets you manage your collection of AI sub-agents—specialized helpers that Claude Code can spawn for specific tasks. You can browse existing agents grouped by where they live (user, project, built-in, plugin), create new ones step-by-step or with AI assistance, edit their tools and colors, and delete ones you no longer need. It is the control panel for the multi-agent system.

💡 Real-world analogy

Think of it like an HR department dashboard for a company. You can view employee profiles (agent detail), hire new staff through a structured interview process (creation wizard) or a recruitment agency (AI generation), assign roles and tools to each person (tool selector), give them a color-coded badge (color picker), and terminate their employment (delete). The dashboard groups staff by department (source: user, project, built-in) and prevents you from creating duplicate positions.

Example: Agent File Format (Markdown with YAML)

// formatAgentAsMarkdown() produces this format for agent files:
function formatAgentAsMarkdown(
  agentType: string,
  whenToUse: string,
  tools: string[] | undefined,
  systemPrompt: string,
  color?: string,
  model?: string,
): string {
  const lines: string[] = [
    '---',
    `agent: ${agentType}`,
  ];

  if (tools) {
    lines.push('tools:');
    tools.forEach(t => lines.push(`  - ${t}`));
  }
  if (color) lines.push(`color: ${color}`);
  if (model) lines.push(`model: ${model}`);

  lines.push('---', '', `# ${agentType}`, '');
  lines.push('## When to use', '', whenToUse, '');
  lines.push('## System prompt', '', systemPrompt);

  return lines.join('\n');
}
