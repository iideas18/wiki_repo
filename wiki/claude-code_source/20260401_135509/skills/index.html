Skills — Extensible Prompt & Skill System

Extensible Prompt & Skill System

The Skills module is Claude Code’s plugin engine for prompt-driven capabilities. It discovers, loads, validates, and registers skill definitions from bundled sources, user directories, project directories, and MCP servers — forming a dynamic library of AI-invokable commands.

💡 Think of it like…

A package manager for AI prompts. Just as npm discovers and loads JavaScript packages from local, global, and registry sources, the Skills module discovers prompt-based capabilities from bundled files, user directories, project hierarchies, and MCP servers — merging them into a unified command palette that the AI agent can invoke at runtime.

🚶 Step-by-Step Narrated Walkthrough

Follow a user invoking the /batch skill from project startup to prompt execution:

  1. App Init — initBundledSkills() iterates over all bundled skill files, calling each register*Skill() function.
  2. Registration — registerBatchSkill() calls registerBundledSkill() with a BundledSkillDefinition containing frontmatter, lazy content, and reference files.
  3. Skill Cache — getSkillDirCommands(cwd) scans managed, user, and project directories. Skills are deduplicated by resolved symlink path.
  4. Conditional Filtering — Skills with paths: frontmatter are separated into conditionalSkills; the rest become immediately available.
  5. Frontmatter Parsing — parseSkillFrontmatterFields() extracts 13+ fields: displayName, description, allowedTools, model, hooks, effort, etc.
  6. Command Creation — createSkillCommand() builds a full Command object with a getPromptForCommand generator that returns the skill’s markdown content.
  7. User Invokes /batch — The AI selects the batch command from the unified palette, triggering content generation.
  8. File Extraction — extractBundledSkillFiles() lazily writes reference files to disk using O_EXCL + 0o600 permissions for security.
  9. Prompt Injection — The skill’s markdown prompt is prepended with a base-directory hint and injected into the conversation context.
  10. Dynamic Discovery — If the batch skill touches new files, discoverSkillDirsForPaths() walks up from each path to find nested .claude/skills/ directories.

Code Examples

Registering a Bundled Skill

import { registerBundledSkill } from "../bundledSkills";

export function registerBatchSkill(): void {
  registerBundledSkill({
    name: "batch",
    displayName: "Batch",
    description: "Parallel bulk change orchestration",
    allowedTools: ["Bash", "Read", "Write", "Edit"],
    getContent: () => SKILL_MD,
    getFiles: () => SKILL_FILES,
    isAvailable: () => true,
  });
}

Dynamic Skill Discovery

import {
  discoverSkillDirsForPaths,
  addSkillDirectories,
  activateConditionalSkillsForPaths,
} from "./loadSkillsDir";

// After a file operation touches new paths
const changedFiles = ["src/components/Button.tsx", "lib/utils.ts"];

// Walk up from each path to find .claude/skills/ dirs
const newDirs = discoverSkillDirsForPaths(changedFiles, process.cwd());

// Load & merge discovered skills (deeper paths override shallower)
await addSkillDirectories(newDirs);

// Activate conditional skills whose paths: patterns match
activateConditionalSkillsForPaths(changedFiles, process.cwd());
