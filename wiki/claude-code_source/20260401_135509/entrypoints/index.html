💡 What Is This Module?

Think of the Entrypoints module like the front doors of a building. A building might have a main lobby entrance (the CLI), a service delivery entrance (the SDK), and a loading dock (the MCP server) — each serving different visitors but all leading into the same interior. No matter which door you walk through, you end up in the same “App Core” of Claude Code. The entrypoints module owns these doors: it decides what each visitor sees first, handles the initial handshake (argument parsing, initialization, trust), and then routes control inward. Internal implementation details never leak out through these doors.

🚶 Step-by-Step Narrated Walkthrough

Follow a single $ claude command as it flows through the Entrypoints pipeline from shell to first prompt:

  1. Shell Invocation — The user runs $ claude. The process starts at cli.tsx, which is the compiled bundle entrypoint. Top-level side-effects set COREPACK_ENABLE_AUTO_PIN=0 and configure heap size for remote environments.
  2. Fast-Path Triage — cli.tsx slices process.argv and checks for fast-path flags. A bare --version prints MACRO.VERSION and exits immediately with zero module loading — sub-millisecond response.
  3. Startup Profiler — If no fast-path matched, startupProfiler.js is dynamically imported and profileCheckpoint('cli_entry') is recorded for performance telemetry.
  4. Special Subcommand Dispatch — cli.tsx checks for subcommands like daemon, remote-control, ps, environment-runner, or --mcp. Each has its own lazy-loaded handler to minimize module evaluation cost for unrelated paths.
  5. Early Input Capture — Before importing the heavy main module, startCapturingEarlyInput() begins buffering stdin keystrokes so nothing is lost during the ~100ms of module loading.
  6. Memoized init() — The init.ts function runs exactly once (memoized via lodash). It enables the configuration system, applies safe environment variables, sets up graceful shutdown handlers, and configures mTLS + HTTP proxy agents.
  7. Network Preconnect — preconnectAnthropicApi() fires a TCP+TLS handshake (~100-200ms) in the background, overlapping with remaining initialization work so the first API call is faster.
  8. Async Side-Effects — Several fire-and-forget tasks launch: OAuth token population, JetBrains IDE detection, Git repository detection, and 1P event logging initialization. None of these block startup.
  9. Telemetry Deferred — Telemetry initialization (~400KB of OpenTelemetry + protobuf) is deliberately not loaded here. It waits until after the trust dialog via initializeTelemetryAfterTrust().
  10. Hand-off to main.ts — cli.tsx dynamically imports main.js and calls cliMain(). The interactive REPL loop starts, and the user sees their first prompt.

CLI Fast-Path Version Check

The CLI entrypoint handles --version with zero dynamic imports for sub-millisecond response:

// cli.tsx — fast-path for --version
const args = process.argv.slice(2);
if (args.length === 1 && (args[0] === '--version' || args[0] === '-v')) {
  console.log(`${MACRO.VERSION} (Claude Code)`);
  return;
}

SDK Query Usage

Embedding Claude Code programmatically via the SDK query() function:

import { query } from '@anthropic-ai/claude-code';

// Single-shot query
const result = query({
  prompt: 'Explain the architecture of this project',
  options: {
    maxTurns: 5,
    allowedTools: ['Read', 'Grep', 'Glob'],
  },
});

for await (const message of result) {
  if (message.type === 'assistant') {
    console.log(message.content);
  }
}

MCP Server Startup

The MCP entrypoint exposes all Claude Code tools over the Model Context Protocol:

// mcp.ts — server initialization
export async function startMCPServer(
  cwd: string, debug: boolean, verbose: boolean
): Promise<void> {
  const server = new Server(
    { name: 'claude/tengu', version: MACRO.VERSION },
    { capabilities: { tools: {} } },
  );

  // List tools handler — converts Zod schemas to JSON Schema
  server.setRequestHandler(ListToolsRequestSchema, async () => {
    const tools = getTools(getEmptyToolPermissionContext());
    return {
      tools: await Promise.all(tools.map(async tool => ({
        ...tool,
        description: await tool.prompt({ /* context */ }),
        inputSchema: zodToJsonSchema(tool.inputSchema),
      }))),
    };
  });

  const transport = new StdioServerTransport();
  await server.connect(transport);
}
