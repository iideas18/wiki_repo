React Terminal UI Components

The components module contains 389 React components that make up Claude Code's terminal interface. Built on the custom Ink framework, these components handle everything from the main App shell and REPL input to permission dialogs, message rendering, tool output display, and interactive configuration. Components use hooks for state management and support both dark/light terminal themes.
