Why This Module Exists

RAGFlow needs operational admin interface (create users, manage workspaces, view logs). Without admin/, operators would manipulate the database directly (risky) or lack visibility. admin/ provides safe, audited operations for SaaS deployments. ### Real-World Analogy admin/ is like AWS console: restricted to admins, with audit trails, not raw DB access.
