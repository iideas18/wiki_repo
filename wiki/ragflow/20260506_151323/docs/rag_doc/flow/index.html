❓ What is this & why?

The flow module orchestrates the entire chunking and extraction pipeline as a directed acyclic graph (DAG). This separation allows different document paths to take different routes (e.g., PDFs skip OCR if already text), enables parallel execution, and makes the pipeline configurable without changing code.

💡 Real-world analogy

Like an assembly line factory. Raw materials (documents) enter at one end. Specialized stations (chunker, extractors) process them in parallel. A central scheduler (DAG executor) routes tasks and manages dependencies. The flow module IS the assembly line controller.
