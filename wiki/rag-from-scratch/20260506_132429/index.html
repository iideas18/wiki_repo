🎯 Project Philosophy

When you first open rag-from-scratch, the most striking design choice is what is missing: no Docker, no Postgres, no API keys, no Python. Everything runs in Node 18+, on a laptop, with files you can cat. The author's wager is that RAG — a topic that sounds intimidating in the LangChain era — becomes obvious if you are forced to write the keyword-scorer, the splitter, the embedding cache, and the rank-fusion equation yourself. The repo is built around this wager.

Two halves split the same idea. examples/ is the curriculum: fifteen numbered lessons (00–06), each a self-contained example.js plus a CONCEPT.md (the why) and a CODE.md (the line-by-line walk). src/ is the library — the layers that have been promoted out of the examples once the abstraction stabilised, named to mirror LangChain.js so that learners can transfer concepts later. The current src/ is honestly partial: chains/, retrievers/, vector-stores/, and prompts/ hold scaffolded index.js stubs because those layers are still being taught in lessons; they will graduate next.

The third design priority is cognitive locality over DRY. Lesson 03 re-implements its own TextSplitter even though src/text-splitters/ exists. Why? Because a reader of lesson 03 must be able to understand it without opening src/. A tab-jumping codebase fails the educational mission. The library exists for downstream consumers; the lessons exist for human eyes.

How src/ & examples/ Connect

The boundary is one-directional and deliberately thin. examples/ imports from src/ only the abstractions that have already been promoted (Document, PDFLoader). Everything else — splitters in lesson 03, vector store wiring in lesson 05 — is re-implemented inline. src/ never imports from examples/. This is the cognitive-locality contract: lessons stay self-readable; the library is downstream of the curriculum, not the reverse.

Key insight: Examples teach. src/ crystallises. Helpers ornament. Reading the empty src/ stubs (chains/, retrievers/, vector-stores/, prompts/) tells you exactly which lessons are next on the author's roadmap.

Build & Tech Stack

Language

JavaScript (ESM only). "type":"module" in package.json. Node 18+. No transpiler.

Build System

None. npm install then node examples/…/example.js. The "no black boxes" promise extends to the build pipeline.

Runtime Deps

node-llama-cpp (local LLM), embedded-vector-db (HNSW), pdf-parse, openai, chalk, ora, boxen, dotenv.

Models

bge-small-en-v1.5.Q8_0.gguf for embeddings (384-d). Qwen3-1.7B.Q8_0 or similar for generation. See DOWNLOAD.md.
