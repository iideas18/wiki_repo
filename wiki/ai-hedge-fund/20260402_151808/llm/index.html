💡 What is this module?

The llm module is the single gateway between the AI Hedge Fund and any language model. It abstracts away provider differences so that agents simply request a model by name and get back a LangChain-compatible chat instance.

"Think of it as a universal remote control for AI models — you press the same buttons regardless of whether you're controlling an OpenAI, Anthropic, Google, or local Ollama model. The remote (factory) knows how to translate your commands for each TV (provider)."

Architecture Overview

The module centres on a ModelProvider enum (13 members) and a get_model() factory function. Model metadata lives in JSON config files, and the factory maps provider names to LangChain chat classes with proper API key wiring.

Data Flow

When an agent needs an LLM, it calls get_model() with a model name and provider. The factory validates the API key, selects the appropriate LangChain class, and returns a configured chat instance ready for .invoke() calls.

    Agent->>Factory: get_model(model_name, provider)
    Factory->>Factory: Lookup ModelProvider enum
    Factory->>Env: Check API key (e.g. OPENAI_API_KEY)
    alt Key Missing

Deep Dive

🏭 Factory Pattern

get_model() encapsulates all provider-specific wiring. Adding a new provider requires only a new enum member, API key check, and LangChain class mapping.

🔧 13 Providers

OpenAI, Anthropic, Google, Groq, DeepSeek, Meta (via OpenRouter), Mistral, Ollama (local), OpenRouter, GigaChat, Azure OpenAI, xAI, and Alibaba.

📋 JSON Configuration

Model lists are stored in JSON for easy addition of new models without code changes. Separated into API models and Ollama models for different deployment targets.

🔑 API Key Validation

Each provider's factory branch checks for the appropriate environment variable (e.g., OPENAI_API_KEY, ANTHROPIC_API_KEY) and raises a clear error if missing.

Code Examples

# Using the factory to get a model instance
from llm.models import get_model, ModelProvider

model = get_model(
    model_name="gpt-4o",
    model_provider=ModelProvider.OPENAI
)
response = model.invoke("Analyze AAPL's Q4 earnings.")
print(response.content)
# ModelProvider enum and LLMModel schema
class ModelProvider(str, Enum):
    OPENAI = "OpenAI"
    ANTHROPIC = "Anthropic"
    GOOGLE = "Google"
    GROQ = "Groq"
    DEEPSEEK = "DeepSeek"
    META = "Meta"
    MISTRAL = "Mistral"
    OLLAMA = "Ollama"
    OPENROUTER = "OpenRouter"
    GIGACHAT = "GigaChat"
    AZURE_OPENAI = "Azure OpenAI"
    XAI = "xAI"
    ALIBABA = "Alibaba"

class LLMModel(BaseModel):
    display_name: str
    model_name: str
    provider: ModelProvider
