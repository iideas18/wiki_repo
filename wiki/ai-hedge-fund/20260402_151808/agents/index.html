💡 What is this?

The agents module is the analytical brain of the AI Hedge Fund. It contains 19 specialized analyst agents — each modeled after a legendary investor — plus support agents for technical analysis, valuation, risk management, and portfolio orchestration. Every agent receives market data, applies its unique investment philosophy, and emits a bullish/bearish/neutral signal with a confidence score. The Portfolio Manager aggregates these signals into final trading decisions.

🎭 Analogy: The Investment Advisory Board
Imagine a boardroom where Warren Buffett, Charlie Munger, Nassim Taleb, and 16 other legendary investors sit around a table. A stock ticker flashes on the screen, and each advisor examines it through their own lens — Buffett looks for moats and intrinsic value, Taleb probes for tail risk and convexity, and the technician studies chart patterns. Each writes their verdict on a card (signal + confidence). A portfolio manager collects all cards, weighs them, considers position limits from the risk manager, and makes the final call. That's exactly what this module does — in code.

    def warren_buffett(state: AgentState, agent_id: str = "warren_buffett"):
    """Analyzes stocks using Warren Buffett's value investing principles."""
    data = state["data"]
    tickers = data["tickers"]
    end_date = data["end_date"]
    start_date = data["start_date"]

    analysis_data = {}
    for ticker in tickers:
        prices = get_prices(ticker, start_date, end_date)
        metrics = get_financial_metrics(ticker, end_date, limit=10)
        insider = get_insider_trades(ticker, end_date, limit=20)

        # Deterministic analysis
        moat_score = analyze_moat(metrics)
        intrinsic_value = compute_dcf(metrics, prices)
        margin_of_safety = (intrinsic_value - prices[-1]) / intrinsic_value

        analysis_data[ticker] = {
            "moat_score": moat_score,
            "intrinsic_value": intrinsic_value,
            "margin_of_safety": margin_of_safety,
            "insider_activity": summarize_insider(insider),
        }

    # LLM generates final signal from analysis
    signal = call_llm(
        prompt=build_buffett_prompt(analysis_data),
        model_name=state["metadata"]["model_name"],
        pydantic_model=WarrenBuffettSignal,
    )
    state["data"]["analyst_signals"][agent_id] = signal
    return state

    Weighted Signal Combination (technicals.py)

    def combine_strategy_signals(signals: dict) -> dict:
    """Combine technical strategy signals with configurable weights."""
    weights = {
        "trend_following": 0.25,
        "momentum": 0.25,
        "mean_reversion": 0.20,
        "volatility": 0.15,
        "stat_arb": 0.15,
    }

    weighted_score = sum(
        signals[strategy]["score"] * weight
        for strategy, weight in weights.items()
        if strategy in signals
    )

    total_weight = sum(
        weight for strategy, weight in weights.items()
        if strategy in signals
    )
    normalized_score = weighted_score / total_weight if total_weight > 0 else 0

    if normalized_score > 0.3:
        signal = "bullish"
    elif normalized_score < -0.3:
        signal = "bearish"
    else:
        signal = "neutral"

    return {
        "signal": signal,
        "confidence": min(abs(normalized_score) * 100, 100),
        "strategy_scores": {k: signals[k]["score"] for k in weights if k in signals},
    }
