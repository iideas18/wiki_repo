What is this?

The CLI module is the front door of the AI Hedge Fund — it collects every parameter needed for a trading run (tickers, analysts, model, dates, capital) before handing control to the graph engine. Think of it as an airline check-in kiosk: it validates your ticket (arguments), asks for your seat preference (interactive prompts via questionary), and prints your boarding pass (a CLIInputs dataclass) before you board the plane.

    Code Examples

    Example 1 — Basic single-run invocation

    # main.py entry point
from src.cli.input import parse_cli_inputs

inputs = parse_cli_inputs(
    description="AI Hedge Fund — Single Run",
    require_tickers=True,
    default_months_back=3,
    include_reasoning_flag=True,
    include_graph_flag=True,
)

# inputs is a CLIInputs dataclass with every field resolved
print(f"Tickers: {inputs.tickers}")
print(f"Analysts: {inputs.selected_analysts}")
print(f"Model: {inputs.model_name} ({inputs.model_provider})")
print(f"Date range: {inputs.start_date} → {inputs.end_date}")
print(f"Capital: ${inputs.initial_cash:,.2f}")

    Example 2 — Programmatic analyst selection (non-interactive)

    from src.cli.input import select_analysts, select_model, resolve_dates

# Pass flags dict to skip interactive prompts
analysts = select_analysts({"analysts_all": False, "analysts": "warren_buffett,cathie_wood"})
# → ["warren_buffett", "cathie_wood"]

# Flag-based model selection
model_name, provider = select_model(use_ollama=False, model_flag="gpt-4.1")
# → ("gpt-4.1", "OPENAI")

# Date resolution with validation
start, end = resolve_dates(None, "2026-03-25", default_months_back=6)
# → ("2025-09-25", "2026-03-25")

    Example 3 — CLIInputs dataclass fields

    from dataclasses import dataclass
from typing import Optional
import argparse

@dataclass
class CLIInputs:
    tickers: list[str]
    selected_analysts: list[str]
    model_name: str
    model_provider: str
    start_date: str          # YYYY-MM-DD
    end_date: str            # YYYY-MM-DD
    initial_cash: float      # default 100_000.0
    margin_requirement: float # default 0.0
    show_reasoning: bool = False
    show_agent_graph: bool = False
    raw_args: Optional[argparse.Namespace] = None
