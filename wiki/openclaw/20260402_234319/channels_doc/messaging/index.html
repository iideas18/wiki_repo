📚 What is this & why does it matter?

When a user sends a message to an AI agent, silence is anxiety-inducing. The messaging sub-module ensures users always get visual feedback — an emoji reaction when the message is received, a changing status as the agent thinks and uses tools, and a typing indicator to show the agent is composing a response.

💡 Real-world analogy

Think of a restaurant kitchen with an open window. When a customer orders (message received), the waiter puts a ticket on the rail (“👀 queued” reaction). The chef picks it up (“🤔 thinking”), uses specialized equipment (“🔧 tool”), and plates the dish (“👍 done”). If the kitchen is backed up, a “⏳ please wait” stall indicator appears. The typing indicator is the waiter walking toward your table — you know food is coming.

Acknowledgement Reactions

Ack reactions confirm that the agent received a message. The scope determines when reactions appear:

ScopeBehavior
allReact to every message
directReact only in DMs
group-allReact to all group messages
group-mentionsReact only when @mentioned in groups (default)
off / noneNever react
export function shouldAckReaction(params: AckReactionGateParams): boolean {
  const scope = params.scope ?? "group-mentions";
  if (scope === "off" || scope === "none") return false;
  if (scope === "all") return true;
  if (scope === "direct") return params.isDirect;
  if (scope === "group-all") return params.isGroup;
  if (scope === "group-mentions") {
    if (!params.isMentionableGroup) return false;
    if (!params.requireMention) return false;
    if (!params.canDetectMention) return false;
    return params.effectiveWasMentioned || params.shouldBypassMention === true;
  }
  return false;
}

Status Reaction State Machine

The status reaction controller provides visual agent state via emoji reactions. Each state transition is debounced, stall timers detect long-running tasks, and terminal states fire immediately.

Typing Indicators

The typing system provides reliable typing indicator management with three safety layers:

  1. Start guard — Tracks consecutive failures, trips the keepalive loop after N failures (default 2)
  2. Keepalive loop — Fires start() every 3s to refresh the typing indicator
  3. TTL safety — Auto-stops typing after 60s maximum duration
export function createTypingCallbacks(params: {
  start: () => Promise<void>;
  stop?: () => Promise<void>;
  onStartError: (err: unknown) => void;
  keepaliveIntervalMs?: number;      // Default: 3000
  maxConsecutiveFailures?: number;    // Default: 2
  maxDurationMs?: number;            // Default: 60000
}): TypingCallbacks
