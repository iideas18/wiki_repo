📚 What is this & why does it exist?

The plugin ecosystem is the extensibility layer of Claude Code. Instead of building every feature into the core CLI, plugins provide modular capabilities that can be installed, combined, and customized. Each plugin can contribute slash commands (user-triggered), agents (AI specialists), skills (auto-invoked knowledge), and hooks (event interceptors).

💡 Real-world analogy

Think of Claude Code as a smartphone and plugins as apps. The phone has basic capabilities (calling, texting), but apps add specialized functions (navigation, banking, photo editing). Similarly, the core CLI handles file operations and bash commands, while plugins add specialized workflows like code review, feature development, and security scanning. Just as apps can communicate with each other, plugins can invoke agents from other plugins.

🚶 Step-by-Step: Feature Development Workflow

Follow a /feature-dev "add user authentication" command through the plugin system:

  1. Command Resolution — CLI finds feature-dev/commands/feature-dev.md and loads the command definition.
  2. Discovery Phase — The command asks clarifying questions about the feature requirements.
  3. Parallel Exploration — 2-3 code-explorer agents launch simultaneously, each analyzing different aspects of the codebase.
  4. File Reading — Agents use Read, Grep, and Glob tools to find relevant code. PreToolUse hooks validate each operation.
  5. Architecture Design — 2-3 code-architect agents propose different approaches (minimal, clean, pragmatic).
  6. User Decision — User selects preferred architecture from presented options.
  7. Implementation — Agents write code using Edit/Write tools. Security hooks check for credentials and dangerous patterns.
  8. Quality Review — 3 code-reviewer agents scan for bugs, style issues, and convention violations in parallel.
  9. Confidence Filtering — Only issues scoring ≥80 confidence are reported, eliminating false positives.
  10. Summary — Plugin produces a summary of changes, files modified, and suggested next steps.
