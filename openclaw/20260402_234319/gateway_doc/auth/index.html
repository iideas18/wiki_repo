Auth — Authentication & Access Control

Gateway Security Layer

The Auth subsystem guards every connection entering the Gateway. It resolves auth modes from configuration, validates credentials across six methods, enforces rate limiting with sliding-window counters, manages device-token pairing, and applies install-time auth policies.

What Is This & Why Does It Exist?

Without authentication, any client could connect to the Gateway and execute arbitrary agent commands. The Auth subsystem ensures that every connection is verified before it reaches internal services.

💡 Real-world analogy

Think of Auth as a multi-layered building security system. The resolveGatewayAuth() function is the security policy that determines which type of badge (token, password, Tailscale, device-token) is required today. The AuthRateLimiter is the turnstile that locks after too many failed badge swipes. authorizeGatewayConnect() is the guard who checks your badge against the policy. auth-install-policy.ts is the building code that mandates what security must be installed before opening day.

Sequence of operations when authorizeGatewayConnect() processes an incoming connection request.

        Auth-->>C: {ok: false, reason}

Code Examples

Resolving Auth Mode

import { resolveGatewayAuth, ResolvedGatewayAuth } from './auth';

const auth: ResolvedGatewayAuth = resolveGatewayAuth({
  config: openClawConfig,
  overrideMode: undefined,
  overrideToken: process.env.GATEWAY_TOKEN,
});
// auth.mode => "token" | "password" | "none" | "trusted-proxy"
// auth.modeSource => "config" | "override" | "default"

Creating a Rate Limiter

import { createAuthRateLimiter, RateLimitConfig } from './auth-rate-limit';

const config: RateLimitConfig = {
  maxAttempts: 10,
  windowMs: 60_000,
  lockoutMs: 300_000,
  exemptLoopback: true,
  pruneIntervalMs: 60_000,
};

const limiter = createAuthRateLimiter(config);
const result = limiter.check('192.168.1.100', 'default');
// result => { allowed: true, remaining: 10, retryAfterMs: 0 }

Authorizing a Connection

import { authorizeGatewayConnect, GatewayAuthResult } from './auth';

const result: GatewayAuthResult = await authorizeGatewayConnect({
  auth: resolvedAuth,
  connectAuth: { token: clientToken },
  req: incomingRequest,
  trustedProxies: ['10.0.0.0/8'],
  authSurface: 'ws-control-ui',
  rateLimiter: limiter,
  clientIp: '192.168.1.100',
  rateLimitScope: 'default',
  allowRealIpFallback: false,
  browserOriginPolicy: 'strict',
});

if (!result.ok) {
  console.error(`Auth failed: ${result.reason}`);
  if (result.rateLimited) {
    console.error(`Retry after ${result.retryAfterMs}ms`);
  }
}
