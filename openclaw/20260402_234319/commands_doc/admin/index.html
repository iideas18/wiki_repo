Commands/Admin/ — Administrative Commands & Management

Permission gating, diagnostics, health checks, and system administration

The Admin sub-module provides all system management capabilities for OpenClaw operators. It implements permission gating through DM policies and allowlists, runs doctor diagnostics to detect and auto-repair configuration and state integrity issues, monitors system health across config, daemon, network, and storage subsystems, and manages session lifecycle with cleanup operations.

📚 What is this & why does it exist?

The Admin sub-module is OpenClaw’s operational control center. It answers questions like “who is allowed to talk to my bot?” (permission gating), “is my system healthy?” (health checks), and “what’s broken and how do I fix it?” (doctor diagnostics). Without these tools, operators would have to manually inspect config files and state directories to troubleshoot problems.

💡 Real-world analogy

Think of Admin like the building manager’s office in a large apartment complex. The permission gating is like the intercom buzzer system — deciding who can enter and who gets turned away. The doctor diagnostics are like a building inspector who checks every apartment for problems (leaky pipes, broken locks) and can auto-fix minor issues. The health check is the daily status board showing which elevators are running, if the power is on, and whether the water pressure is normal.
