💡 Analogy — A Multi-Stage School Education

Think of the training pipeline as a student progressing through school. Pretraining is elementary school—learning the basics of language from a massive textbook. SFT is high school—learning to follow instructions from a tutor. DPO/PPO/GRPO/SPO are university seminars—refining judgment by comparing good and bad answers under expert feedback. LoRA is a crash course—quickly adapting knowledge without rewriting everything. Distillation is mentorship—a senior model teaching a junior one. Reasoning is the final thesis—learning to show your work step by step.

5. Deep-Dive Hub

🎯 RLHF Pipeline

DPO uses Bradley-Terry preference model (β=0.1). PPO adds critic + GAE with clipped objective. GRPO generates 8 responses and normalizes group-relative advantages. SPO uses a single generation with Bayesian adaptive baseline (ρ = 2^(−kl/D_half)).

📉 Cosine LR & Grad Accumulation

get_lr() implements cosine annealing: lr × (0.1 + 0.45 × (1 + cos(π·step/total))). Gradient accumulation allows effective batch sizes N× physical batch. Gradient clipping at norm 1.0 prevents explosion.

💾 Checkpoint & Resume

lm_checkpoint() saves model, optimizer, epoch, step, wandb_id, and world_size. SkipBatchSampler skips already-processed batches on resume. Supports multi-GPU DDP state restoration.

🧬 Knowledge Distillation

Student-teacher framework: total_loss = α·CE + (1−α)·T²·KL(student ‖ teacher). Default α=0.5, T=1.5. Teacher is frozen; only student gradients flow. Temperature softens probability distributions for richer supervision signal.

Cosine Learning Rate Schedule

trainer_utils.py — get_lr() 
import math

def get_lr(current_step, total_steps, lr):
    """Cosine annealing with warm floor at 10% of peak LR."""
    return lr * (0.1 + 0.45 * (1 + math.cos(math.pi * current_step / total_steps)))

DPO Loss with Bradley-Terry Model

train_dpo.py — dpo_loss() 
import torch
import torch.nn.functional as F

def dpo_loss(policy_chosen_logps, policy_rejected_logps,
             ref_chosen_logps, ref_rejected_logps, beta=0.1):
    """Direct Preference Optimization with frozen reference model."""
    chosen_rewards = beta * (policy_chosen_logps - ref_chosen_logps)
    rejected_rewards = beta * (policy_rejected_logps - ref_rejected_logps)
    return -F.logsigmoid(chosen_rewards - rejected_rewards).mean()

Knowledge Distillation Loss

train_distillation.py — distillation_loss() 
def distillation_loss(student_logits, teacher_logits, temperature=1.5):
    """KL divergence scaled by T² for knowledge transfer."""
    s_probs = F.log_softmax(student_logits / temperature, dim=-1)
    t_probs = F.softmax(teacher_logits / temperature, dim=-1)
    return (temperature ** 2) * F.kl_div(s_probs, t_probs, reduction='batchmean')
