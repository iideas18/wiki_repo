🏭 Think of it like a factory assembly line. The model/ directory is the blueprint for MiniMind's neural "factory." Raw token IDs enter the conveyor belt (embed_tokens), pass through a series of identical processing stations (MiniMindBlock), each of which inspects context (Attention) and refines features (FeedForward). At the end of the line, a quality-control head (lm_head) stamps out the next-token prediction. The MoE option swaps a single FFN station for a team of specialist workers, each activated only when their expertise is needed. LoRA lets you fine-tune the factory by clipping small adapter jigs onto existing machinery — no need to retool the whole line.

1 · Architecture Overview

MiniMind follows a decoder-only Transformer design compatible with Hugging Face's PreTrainedModel. The class hierarchy reflects clean separation of concerns: configuration lives in MiniMindConfig, the backbone in MiniMindModel, and the language-modelling head in MiniMindForCausalLM.

5 · Deep-Dive Hub

🔵

Attention Mechanism

Grouped-Query Attention with 8 Q-heads and 2 KV-heads. Supports Flash Attention via scaled_dot_product_attention and autoregressive KV caching for fast generation.

🟡

MoE Routing

Top-2 gating over 4 routed experts plus 1 shared expert. Softmax scoring with Kaiming-uniform init. Auxiliary load-balancing loss at token or sequence level keeps experts evenly utilised.

🟢

RoPE & YaRN

Rotary position embeddings with θ=1e6 and max 32768 positions. YaRN scaling (factor 16, β_fast=32, β_slow=1) for long-context extrapolation: f'(i) = f(i)·((1−γ) + γ/s).

🔴

LoRA Adapter

Rank-r decomposition injected into all square projection layers. A-matrix Gaussian-init, B-matrix zero-init ensures no change at start. Only ~0.5% extra parameters.

8.1 · SwiGLU Feed-Forward (from model_minimind.py)

class FeedForward(nn.Module):
    def __init__(self, config: MiniMindConfig):
        super().__init__()
        hidden_dim = int(config.hidden_size * 8 / 3)
        hidden_dim = 64 * ((hidden_dim + 63) // 64)  # round to 64
        self.gate_proj = nn.Linear(config.hidden_size, hidden_dim, bias=False)
        self.up_proj   = nn.Linear(config.hidden_size, hidden_dim, bias=False)
        self.down_proj = nn.Linear(hidden_dim, config.hidden_size, bias=False)
        self.act_fn    = ACT2FN[config.hidden_act]

    def forward(self, x):
        return self.down_proj(self.act_fn(self.gate_proj(x)) * self.up_proj(x))

8.2 · LoRA Injection (from model_lora.py)

class LoRA(nn.Module):
    def __init__(self, in_features, out_features, rank=8):
        super().__init__()
        self.A = nn.Linear(in_features, rank, bias=False)
        self.B = nn.Linear(rank, out_features, bias=False)
        nn.init.normal_(self.A.weight, std=1/rank)
        nn.init.zeros_(self.B.weight)

    def forward(self, x):
        return self.B(self.A(x))

def apply_lora(model, rank=8):
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear) and module.in_features == module.out_features:
            lora = LoRA(module.in_features, module.out_features, rank)
            setattr(module, 'lora', lora)
            original_forward = module.forward
            module.forward = lambda x, of=original_forward, l=lora: of(x) + l(x)

8.3 · YaRN-scaled RoPE Frequency Computation (from model_minimind.py)

def precompute_freqs_cis(dim, end, theta=1e6, scaling_config=None):
    freqs = 1.0 / (theta ** (torch.arange(0, dim, 2).float() / dim))
    if scaling_config is not None:
        # YaRN: f'(i) = f(i) * ((1 - gamma) + gamma / scale)
        factor    = scaling_config["factor"]        # 16
        beta_fast = scaling_config["beta_fast"]      # 32
        beta_slow = scaling_config["beta_slow"]      # 1
        # Compute linear ramp gamma ∈ [0, 1]
        low  = math.floor(dim * math.log(end / (beta_fast * 2 * math.pi)) / (2 * math.log(theta)))
        high = math.ceil(dim * math.log(end / (beta_slow * 2 * math.pi)) / (2 * math.log(theta)))
        gamma = (torch.arange(0, dim // 2).float() - low) / (high - low)
        gamma = gamma.clamp(0, 1)
        freqs = freqs * ((1 - gamma) + gamma / factor)
    t = torch.arange(end, dtype=torch.float32)
    freqs = torch.outer(t, freqs)
    return torch.cos(freqs), torch.sin(freqs)
