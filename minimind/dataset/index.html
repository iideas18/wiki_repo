🍳 Kitchen Analogy

Think of the dataset module as ingredient preparation stations in a professional kitchen. Each station (Dataset class) takes raw ingredients (JSONL data) and prepares them differently depending on the dish being made — the Pretrain station washes and chops text into uniform pieces, the SFT station marinates conversations into chat templates, the DPO station carefully selects the best and worst preparations for comparison, and the RLAIF station stages prompts for the chef (RL agent) to improvise with. Every station outputs precisely formatted batches, ready for the training "oven."

    Loading an SFT Dataset

    Python — SFT dataset initialization
    from dataset.lm_dataset import SFTDataset
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("MiniMind2")
dataset = SFTDataset(
    data_path="data/sft_train.jsonl",
    tokenizer=tokenizer,
    max_length=512
)

# Each item: (input_ids, labels, loss_mask)
X, Y, loss_mask = dataset[0]
print(f"Sequence length: {len(X)}")
print(f"Active loss tokens: {loss_mask.sum().item()}")
